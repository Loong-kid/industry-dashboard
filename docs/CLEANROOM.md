# 클린룸/공조

경로: `#/semicon/materials/cleanroom`. 사용자가 선정한 국내 4사(한양이엔지 045100, 세보엠이씨 011560, 신성이엔지 011930, 케이엔솔 053080), 대만 3사(UIS 2404 TWSE, L&K 6139 TWSE, Acter 5536 TPEx), 말레이시아 Kelington 0151 Bursa만 등록한다.

- 전사 연결 우선 실적이다. 클린룸 시공·공조·초고순도 배관 역할을 구분한다. 한국 연결 미공시 기간은 별도임을 원문에서 확인할 수 있다. UHP/CE/엔지니어링 매출 비중을 반도체 클린룸 단독 비중으로 쓰지 않는다.
- 한국: 기존 DART 정규화·보존 로직을 재사용한다. 최초 2015년부터 원문을 조회하고 비교표시로 확보되는 2014년 연간을 유지한다. 케이엔솔은 법인 공시가 확보되는 기간부터. 이름 변경 전 원방테크 포함.
- 대만: 과거 MOPS HTML 원문, 회사 홈페이지 연결 PDF, TWSE/TPEx 공개 `t187ap06_*_ci` 손익 공시. 원문 천 TWD를 백만 TWD로 환산한다. 회전된 PDF는 회전 제거 후 읽고 연결·단위·열 개수를 검증한다. L&K의 연도별 A/04 파일에 연결/별도가 섞여 있어 반드시 제목을 확인한다. 이전 연도 비교 열은 직접 확보한 해당 연도 자료가 없을 때만 쓴다. L&K 확보 분기는 2020년부터이다.
- 한탕·야샹의 홈페이지 미게재 2026 Q2 손익은 MoneyDJ 공시 재게시 표의 실제 3개월·6개월 누적을 검토한 원장으로 보완한다. 야샹 Q1은 상반기−Q2이며 최신 Q3은 거래소 9개월 누적−확인한 상반기 누적이다. CAPEX는 추정하지 않는다. 재게시 자료 출처는 개별 점에서 표시한다.
- 대만 OpenAPI는 최신 누적이다. `YTD` 선택지에 표시하며 이전 누적 원문을 확보한 항목만 단독 분기로 차분한다. 최신 9개월 금액을 분기 값으로 쓰거나 미완결 연도를 연간으로 쓰지 않는다.
- Kelington: 공식 Financial Information의 2014년 이후 분기·연간 매출, PBT, PAT를 원장으로 보존한다. PBT는 영업이익이 아니므로 명확히 세전이익으로 표기한다. 원장 간 정정 차이를 임의 배분하지 않는다. 2023 Q4 PBT의 `46.896`은 단위가 모호해 공백이다. CAPEX는 확인한 2024/2025 연간 및 2025/2026 상반기 현금 취득만 표시한다. 2025 연간 CAPEX 출처는 미감사 Q4 보고서이다.
- 주가·실적 TTM PER/PBR: 기존 반도체 수집·확대 차트를 재사용하며 현지 상장 종목 8개를 등록한다. 주가·EPS·BPS 원천과 기준은 기존 밸류에이션 카드에 표시한다.

`update-cleanroom.yml`: 매일 KST 09:25 DART·공식 IR·거래소 OpenAPI 확인. 원문 실패 시 회사별 마지막 확보 이력과 성공 확인일을 유지한다. Kelington 매출·PBT·PAT는 공식 HTML 자동 확인, CAPEX는 위에서 확인한 보고서 스냅샷으로 새 현금흐름 발표 시 원장 검토가 필요하다. 밸류에이션은 기존 KST 08:10 수집. 프론트는 해당 탭에서만 자료를 읽으며 밴드/주가 상세는 기존 지연 로딩을 유지한다.

검증: `python -m unittest discover -s scripts -p test_cleanroom.py -v`, 전체 회귀 `python scripts/run_ci_tests.py`. `--from-state`는 네트워크 없이 차트 문서를 재생성한다. 과거 IR 추가 수집은 `scripts/import_cleanroom_ir.py`, 국내 최초 전체 이력은 `scripts/fetch_cleanroom_domestic.py --refresh --full-history`.
