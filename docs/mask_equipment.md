# 마스크 장비 지표

포토마스크 탭에서 패터닝 업체 다음에 JEOL → NuFlare → Mycronic 순으로 표시한다. 장비 수주·납품은 향후 포토마스크 생산능력의 참고 지표이며 블랭크마스크의 당기 판매 장수와 일치하지 않는다. 세 회사의 금액이나 대수를 합쳐 전체 시장으로 표시하지 않는다.

## JEOL

- 공식 [IR Data Book](https://www.jeol.com/ir/data_book/)의 최신 Excel 링크를 찾아 표 이름·행·단위와 캐시된 숫자를 읽는다. 추가 Python Excel 라이브러리는 필요 없다.
- `4-2`의 MBMW 플랫폼 및 싱글빔 3050/3200 수주·매출인식 대수. 분기 버튼은 MBMW FY2018 Q1부터, 싱글빔 FY2019 Q1부터이며 연간 버튼으로 각각 FY2012, FY2018부터 확인할 수 있다. 2026-10-08 수집 기준 최신은 FY2026 Q1(2026-06-30).
- MBMW는 JEOL의 **플랫폼** 대수다. IMS의 완성 멀티빔 장비나 글로벌 EUV 마스크 라이터 판매 대수로 해석하지 않는다. 싱글빔에는 스폿빔 웨이퍼 직접묘화 장비를 섞지 않는다.
- 산업기기 매출·영업이익은 2014-03-31(FY2013 Q4)부터 2026-06-30까지 50개 분기. FY2016 Q1 이후 41개 분기는 Data Book `2-1`의 단일 분기다. 이전 9개 분기는 공식 [일본어 결산 공시](https://www.jeol.co.jp/ir/financial_results/)의 `産業機器事業` 외부 매출·세그먼트 영업이익 누적값에서 계산한다. Q2·Q3는 직전 누적 차분, Q4는 연간−9개월이며 원표의 백만 엔 절사를 유지한다. 다음 공시의 비교표가 정정한 값을 우선한다. 각 점에 차분에 사용한 두 PDF·페이지를 남긴다.
- 산업기기 수주액·잔고는 2014-03-31(FY2013)부터 2026-03-31까지 13개 연간. 과거 3개 연도는 [유가증권보고서](https://www.jeol.co.jp/ir/sec_report/) PDF p.14 `生産、受注及び販売の状況`의 산업기기 행을 사용한다. FY2013 수주 7,755·잔고 2,753, FY2014 수주 8,417·잔고 3,734, FY2015 수주 12,949·잔고 6,695백만 엔. 이후 10개 연도는 Data Book `12`다. 산업기기에는 다른 반도체·산업 장비도 포함된다.
- FY는 4월 시작 연도로 표시하고 관측 날짜는 실제 분기말/결산말을 쓴다. 백만 엔 ÷ 100 = 억 엔. 공시된 단일 분기값을 직접 사용한다. Excel의 빈칸·대시는 미공시로 남기고 실제 숫자 0만 0으로 표시한다.
- 연간 값과 4개 분기의 합을 대조한다. 대수는 정확히 일치해야 하며 백만 엔 공표값은 3백만 엔 이내의 절사 차이만 허용한다. 원문 링크에는 Excel 표 이름과 셀 위치를 기록한다. PDF는 연간 표만 있는 별도 버전이므로 분기 수치의 출처로 오인해 연결하지 않는다.

## NuFlare

- 2014-03-31(FY2013)~2026-03-31(FY2025), 13개 연간 회사 전체 **단독** 실적. 2014~2019년 3월 결산은 회사가 작성한 결산 원문 p.2 `個別業績の概要`다. 연결 실적을 이어 붙이지 않는다. 예를 들어 2019년 3월 결산 매출은 연결 578.22가 아닌 단독 573.20억 엔이다.
- 회사 작성 원문은 IRBANK의 공개 보관 PDF로 확인했다: [2015년 결산 원문](https://f.irbank.net/pdf/20150610/140120150610413615.pdf#page=2), [2017년 결산 원문](https://f.irbank.net/pdf/20170512/140120170512469646.pdf#page=2), [2019년 결산 원문](https://f.irbank.net/pdf/20190510/140120190510420719.pdf#page=2). 각각 전년도 비교표도 포함한다.
- 2020~2022년 3월 결산은 관보 결산공고 전재([2020](https://catr.jp/companies/885b8/48664/settlements/498e4/160813), [2021](https://catr.jp/companies/885b8/48664/settlements/3d4a8/209433), [2022](https://catr.jp/companies/885b8/48664/settlements/d8c9a/258797)). 매출/영업이익은 402.73/62.64, 434.49/62.28, 365.42/40.97억 엔이다. 과거 상장 시점의 2020년 매출 전망 440억 엔과 구분한다.
- FY2022~FY2025는 [공식 업적 추이](https://www.nuflare.co.jp/recruit/about/report/)의 그래프를 시각 확인한 정수 억 엔 값이다. 이전 자료의 소수점 정밀도를 억지로 맞추거나 최신 그래프의 숫자를 비공식 소수점으로 바꾸지 않는다. 전자빔 마스크 묘화·마스크 검사·에피택셜 성장 장비 전체를 포함하며, 연간값을 분기로 배분하지 않는다.
- 2026-10-15 검토값과 JEOL의 과거 누적·연간 수치는 `manual/mask_equipment.json`에 출처·페이지와 함께 보관한다. 일일 갱신에서도 기존 이력이 사라지지 않도록 빌더에서 합친다.

## Mycronic

- [공식 IR 아카이브](https://www.mycronic.com/investors/financial-reports/)에 내장된 공개 MFN 위젯의 보고서 링크를 사용한다. 위젯 식별자는 공개 페이지에서 읽으며 로그인·API 키가 필요 없다.
- Pattern Generators 수주액·매출·수주잔고·EBIT·매출총이익률은 보고서 마지막 `Quarterly data`의 해당 사업부 행이다. 초기 수집은 Q2 2020/2022/2024/2026의 8분기 표로 2018 Q3~2026 Q2, 32개 분기를 확보했다. 새 보고서의 비교표가 과거 값을 수정하면 최신 공표값을 우선한다.
- 분기 수주/매출 = 같은 분기 수주액 ÷ 매출액. TTM = 연속 4개 분기 수주 합 ÷ 매출 합. 분기 비율 평균으로 계산하지 않는다. 4개 연속 관측이 없는 경우 TTM을 비워 둔다. EBIT 이익률은 공시 금액으로 계산하므로 회사의 반올림 이익률과 미세한 차이가 날 수 있다.
- 2026 Q2 TTM의 분기 매출 합은 3,258백만 SEK로 별도 공표 TTM 3,257백만 SEK와 1백만 SEK 반올림 차이가 있다. 분기 원표를 유지하고 수주/매출 비율도 2,606 ÷ 3,258로 계산한다.
- 납품·잔고 대수는 2024 Q1~2026 Q2 각 보고서 PDF p.4 본문을 확인한 수기 자료다. 2025 Q3·Q4의 qualification SLX 매출 인식은 당기 신규 납품으로 세지 않는다. 2025 Q1의 기존 Prexision 주문 업그레이드를 순신규 수주로 해석하지 않도록 수주 대수는 별도로 추정하지 않았다.
- 최신 납품 예정 일정은 대수 차트 설명에 표시한다. 2028년 맞춤형 SLX는 분기가 공개되지 않아 임의로 2028 Q4 관측값을 만들지 않는다. 예정은 확정 실적이 아니다.
- 사업부는 디스플레이·반도체 레이저 마스크 라이터와 서비스 등을 포함한다. 2026년 Cowin DST 인수로 리페어 장비 범위가 추가됐다. 2026 Q2의 맞춤형 SLX 주문(USD 27~30m)은 비반복 건이며 분기 수주액에는 서비스·환율·제품 믹스·인수 효과가 포함된다. 금액을 장비 대수로 나눈 값을 순수 장비 ASP로 표시하지 않는다.

## 재생성·갱신

```powershell
python scripts/fetch_mask_equipment.py --backfill
python scripts/fetch_mask_equipment.py --offline
python -m unittest discover -s scripts -p test_mask_equipment.py
```

일일 데이터 갱신 workflow에서 JEOL 최신 Data Book과 Mycronic 최신 보고서를 수집한다. NuFlare와 Mycronic 대수·예정 일정은 별도의 검토 스냅샷으로, 자동으로 새 본문 숫자를 추정하지 않는다. 자료별 관측 종료일과 수집/검토일을 표시하며, 원문 레이아웃 변경·대조 실패 시 캐시와 차트 파일을 교체하기 전에 실패한다.
