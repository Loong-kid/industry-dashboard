# 반도체 소부장 · 세정

`#/semicon/materials/cleaning`에 장비·부품·소재와 나란히 세정 카테고리를 추가한다. 장비 부품을 재사용하기 위한 세정·코팅·재생 서비스 기준이며 웨이퍼 세정 장비 제조사는 기존 전공정 장비에 둔다.

2026-11-03 확인한 국내 코미코(183300), 한솔아이원스(114810), 원익QnC(074600)와 미국 Ultra Clean(UCTT), Enpro(NPO)를 비교한다. 공식 사업 소개와 범위·사명 변경·인수 이력은 `manual/semicon-cleaning/companies.json`에 보존한다. 미코는 코미코의 모회사이므로 별도 비교기업으로 중복 등록하지 않았다. 세정 단독 손익을 추산하지 않으며 모두 상장 법인 전사 실적이다. 코미코의 세라믹 부품, 한솔아이원스의 정밀가공, 원익QnC의 쿼츠·원재료, UCT의 Products, Enpro의 Sealing 등 다른 사업도 포함한다.

국내는 기존 DART 원문 수집·기간 정규화 모듈을 재사용한다. 연결 우선, 미공시 기간은 별도 기준을 표시한다. 연간은 공시된 완결 회계연도, 분기는 실제 3개월 공시 또는 동일 회계연도·재무제표 범위의 누적 차감이다. CAPEX는 현금흐름표 유형자산 취득 지출이며 무형자산·M&A·비현금 리스·고객사 투자는 제외한다. 미공개 값·호환되지 않는 누적 차분은 공백으로 둔다. 미국 SEC는 실제 52/53주 종료일과 GAAP 영업이익을 유지하며 매출의 Including/Excluding Assessed Tax 태그 변경도 추적한다.

`update-semicon-cleaning.yml`이 매일 KST 08:50에 신규·정정 공시를 확인한다. 회사별 조회 실패 시 마지막 성공 이력과 수집일을 유지하고 실패 상태만 갱신한다. 새 공시가 없는 기간을 생성하지 않는다. 최초 이력은 2015년부터의 DART 원문과 전기 비교표시, 2014년 이후 SEC Company Facts에서 수집했다. 원문은 검토용 캐시에 두고 공개 산출물은 정규화된 `cleaning_state.json`과 15개 실적 차트다. API 키는 기존 CI Secret을 사용하며 파일·로그·공개 JSON에 저장하지 않는다.

주가·실적 TTM PER·PBR은 기존 `update-semicon-valuation.yml`의 KST 08:10 수집에 함께 등록한다. 주가는 2014년 또는 실제 상장 이후 일별 종가를 보유하고 개별 기업이 화면에 들어올 때 불러온다. PER/PBR 분모 이력은 공급자가 제공하는 실제 공시 기간만 표시하며 전망치·적자 PER·음수 순자산 PBR을 만들지 않는다. 상세 밴드는 기존 돋보기 창에서 확대할 수 있다. 주가 수집은 기존 기업의 파일을 대체하지 않고 5개 신규 기업을 같은 원장에 추가했다.

검증: `python -m unittest discover -s scripts -p test_semicon_cleaning.py -v`, `python scripts/run_ci_tests.py`.
