# 게임 실적의 USD 표시

회사 실적, 공식 개별 게임 매출, 플랫폼의 금액 지표는 **백만 USD**로 표시한다. 원본 `companies.json`, `revenue.json`, `platforms.json`의 원통화 금액·공시 출처는 변경하지 않는다. 이용자 수·계정·판매 대수의 단위는 유지한다. EGS 이용자 지출·Fab 창작자 수익은 회사 회계 매출과 구분한다.

## 환산

- 원통화가 USD이면 원자료 금액을 그대로 사용한다.
- KRW·JPY·CNY·PLN은 [ECB 일별 기준환율](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)의 [전체 이력 CSV ZIP](https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.zip)을 무료로 가져온다. 키·유료 서비스가 필요 없다.
- 각 고시일에 `원통화/EUR ÷ USD/EUR = 원통화/USD`를 계산한다. 실적의 실제 `start`~`date`에 해당하는 고시일의 산술평균을 적용한다. 주말·휴일 환율을 새로 만들거나 기간 말 환율로 대체하지 않는다.
- `원통화 금액(백만) ÷ 평균 원통화/USD = USD 금액(백만)`. 중간 계산을 반올림하지 않고 화면에서만 반올림한다.
- 분기는 해당 분기, 연간은 해당 회계연도 전체 고시일 평균이다. 연간 평균을 분기 평균의 단순 평균으로 만들지 않는다. 따라서 연간 환산액과 분기 환산액의 합은 정확히 일치하지 않을 수 있다.
- 분기 공시값을 우선 사용하며, 연간−9개월 등으로 산출한 분기도 원통화 계산을 마친 다음 해당 분기 환율로 환산한다.
- 외국 상장사의 편의상 USD 환산 공시는 기말 환율을 사용할 수 있으므로 별도로 섞지 않는다. 이 화면의 비달러 원자료에는 동일한 기간 평균 방법을 일관되게 적용한다. 환산액은 비교용이며 회사의 공시 USD 수치와 차이가 날 수 있다.

## 데이터와 결측

`scripts/fetch_game_fx.py`는 필요한 통화·실적 기간의 환율을 `data/games/fx.json`에 별도 저장한다. 키는 `통화|시작일|종료일`이다. 평균, 관측 개수, 첫·마지막 고시일, 실제 조회 시각, ECB URL, 원본 ZIP SHA-256, 방법을 보존한다. 갱신 워크플로는 재무·플랫폼 수집 뒤 실행한다.

평일의 85% 미만 관측, 기간 양끝 또는 내부 7일 초과 공백은 불완전한 기간으로 처리한다. 요청 실패 시 정확히 일치하는 기존 완료 기간과 실제 조회일을 유지한다. 신규 미확보 기간은 USD 금액을 표시하지 않으며 현재 환율·인접 분기 환율·0으로 채우지 않는다. 원통화가 USD인 항목은 환율 수집과 독립적으로 표시한다.

## 화면과 내보내기

금액 버튼에 마우스를 올리거나 키보드로 포커스를 주거나 모바일에서 누르면 원통화 금액·실적 기간·평균환율·관측 범위가 나온다. Escape, 바깥 클릭 또는 금액이 화면 밖으로 이동하면 메모가 닫힌다. 차트 툴팁에도 원통화와 환산 근거를 표시한다.

게임사 실적은 다른 산업과 같은 `renderCard` 구성 요소를 사용한다. 기업마다 매출·영업이익·순이익 그래프를 바로 펼쳐 보여주고, 각 카드에서 분기/연간을 독립적으로 전환한다. 전체 차트 기간을 바꾸면 카드 전체를 같은 유형으로 전환한다. 최초 진입 시 분기 자료 없는 회사는 연간을 표시한다. 각 카드의 ‘표 보기’로 실제 기간별 수치·공시 원문과 원통화 메모를 확인한다. 순이익 미공개 부문은 빈 카드와 안내를 표시하며 0으로 채우지 않는다.

지역·사업·검색은 그래프와 보조 표에 함께 적용한다. 업체 목록과 같은 결산일의 비교표는 접힌 보조 영역에 둔다. 회사 비교는 통화 필터 없이 같은 결산일과 분기/연간 유형으로 정렬한다. 전년 대비 매출은 USD 기준이며 환율 영향이 포함된다. 비교표 YoY 메모와 CSV에 원통화 YoY를 함께 남긴다. 영업이익률은 원통화 비율과 같다. 전체 업체 목록은 각 회사의 최근 보유 기간이므로 연간·분기가 섞일 수 있으며 이를 별도 순위로 해석하지 않는다.

회사·플랫폼 CSV는 표시 금액/단위와 원래 금액/단위, 적용 환율·방법·조회일·출처를 함께 담는다. 회사 CSV에는 모든 실적 시작일·종료일, 환율 관측 범위·개수, 공시 출처도 포함한다.
