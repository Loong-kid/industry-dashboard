# 한국 광물 수출입

원자재 → **한국 수출입** 탭. KOMIS 대한민국 핵심광물 수급지도에 공개된 **73개 광종을 전부** 배치했다. 146개 금액·물량 카드와 국가별 비교표, 277개 물질흐름 구분의 누적 실적, 574개 HS 코드 목록을 제공한다. 기업 지표는 이 작업에 포함하지 않는다.

출처: [KOMIS 대한민국 광물 수급지도](https://www.komis.or.kr/Komis/MnrlMap/Korea). 원사이트에 명시된 원천은 관세청 공공데이터 포털 공개 수출입 통계다. 월 자료는 다음 달 15일, 연 자료는 다음 해 3월 중순 확정한다고 안내한다.

## 제공 범위

- 연간: 2014~2025년 공개 이력. 일부 광종은 중간 연도가 없고, 0으로 보간하지 않는다.
- 동기간 누적: 2025년과 2026년 각각 1~8월 비교.
- 최근 월: 2026년 7월 / 8월 개별 월 실적 비교. 월간 전체 역사 시계열은 포함하지 않는다.
- 국가: 2025년 연간 / 2026년 1~8월 누적, 수입국·수출국 각각 금액 순 상위 최대 30개국. 전체 합계 대비 금액·물량 비중과 표시 국가의 합계 비중을 안내한다.
- 품목: 광종별 물질흐름 구분(기초원료·기초금속·가공금속·스크랩 등)의 최신 연도 누적 수입·수출 금액·물량. 구분 합계가 광종 전체와 불일치하는 경우가 있어 전체를 이 표에서 재계산하지 않는다.
- HS: 해당 광종의 공개 10자리 HS 코드와 품목명 전부. HS 개별 코드별 시계열은 생성하지 않았다.

원자료 **USD → 백만 USD(÷1,000,000), kg → 톤(÷1,000)**. 제품 총중량이며 순수 금속 함유량이 아니다. 광석·금속·화합물·가공품·스크랩이 섞인 광종 묶음이므로 국내 광산 생산량·최종 소비량과 직접 대조하거나 광물 간 합산하지 않는다. 광종 간 HS 중복도 가능하다. 수출을 빼서 국내 소비량을 산출하지 않는다.

## 수집·표시 검증

`scripts/fetch_korea_mineral_trade.py` → `data/commodities/comm_korea_mineral_trade.json`. 전체 73개 목록을 `scripts/korea_mineral_trade_registry.json`으로 고정하고 변경 시 검토를 요구한다. 금액·중량은 원단위를 JSON에 보존하고 표시 단계에서만 변환한다.

`getLineChartDataKorea`는 5년 구간의 **연간** 자료를 반환한다. 월 모드로 요청해도 연간 자료가 반환되므로 이를 월간 이력으로 오인하지 않는다. 연간 창을 나눠 전체 이력을 확보하고, 최신 확정 연도의 국가표 전체 합계와 일치하는지 검증한다.

정확한 기간의 `getListKoreaData`는 `sumIncmAmt / sumIncmWeig / sumExpAmt / sumExpWeig`를 전체 분모로 사용한다. `listCount=300`이어도 실제 응답은 최대 30개다. 국가표 합계로 전체를 만들거나 상위 국가를 100%로 정규화하지 않는다. 코드가 있으나 이름이 없는 국가(예: ZZ)는 **국가명 미제공(코드)**으로 보존한다.

빈 응답은 미공개로 유지한다. 실제 0 응답만 0으로 표시한다. 연도·기간·숫자·중복·국가 합계·수입/수출 순위의 전체 합계 일치·과거 이력 보존을 검증한다. 전체 배치가 유효할 때만 원자적으로 공개 JSON을 교체한다. 실패하면 이전 파일을 보존하고 수집 단계가 실패한다.

매일 KST 07:30 기존 update-data 작업에서 별도 단계로 새 공표·정정을 확인한다. 원자료 공표는 월간이며 일간 자료를 만들어내지 않는다. 현재 연도와 아직 확정 시기가 오지 않은 직전 연도를 연간 확정치로 표시하지 않는다.
