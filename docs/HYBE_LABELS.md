# 하이브 레이블 매출·계약

경로 `#/entertainment/hybe`. 기존 하이브 연결 매출·영업이익·CAPEX 아래에 국내/해외 매출 비교 카드, 레이블 재무 표와 그룹별 전속계약 표를 추가한다. 차트 크기와 기존 엔터테인먼트 비교 화면은 유지한다.

## 재무 원천과 범위

`scripts/fetch_hybe_labels.py`는 기존 `data/entertainment/state.json`이 검증한 실제 정기보고서 접수번호를 사용한다. API 키 없이 DART 공개 보고서의 연결회사의 개요 주석에서 **종속기업의 요약 재무정보**와 소유지분율을 읽는다. 잠정 전사 실적에는 레이블별 공시가 없으므로 레이블 수치를 역산하지 않는다. 등록 시점 최신 레이블 주석은 [2026년 반기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260814004127)다.

원문 천원은 KRW 백만으로 바꿔 보관하고 화면은 억원으로 표시한다. 비교 수치는 전년 같은 분기·연간으로 저장한다. 같은 기간이면 당기 원문을 비교표보다 우선하고 같은 당기 자료 중 최신 접수를 우선한다. 분기는 같은 법인의 같은 회계연도 누적−직전 누적이다. 중간 누적이 없으면 차감하지 않으며 자산·부채는 기말 잔액 그대로다. 순손익을 영업이익으로 표시하지 않는다. 차감 매출이 음수인 구간은 검토 대상으로 비운다.

실제 확보 이력은 2019년 비교 공시부터다. 빅히트뮤직은 2021년 물적분할 후 법인만 연결하며 이전 하이브 전체 매출을 붙이지 않는다. 취득·편입 첫해는 일부 기간만 공시될 수 있다. 지분율은 해당 보고서 당기말 소유지분율이며 표의 그룹 열은 최신 전속 명단으로 과거 매출 배분을 뜻하지 않는다.

법인별 매출은 내부거래 제거 전이고 HYBE America 등 지역 연결법인은 산하 법인을 포함하므로 합산하지 않는다. Big Machine·Quality Control·SB Projects·JCONIC 등 별도 요약 매출이 없으면 미공개로 표시한다. 빅히트 매출을 BTS 매출, ADOR 매출을 뉴진스 개인 매출로 배분하지 않는다. `manual/entertainment/hybe-labels.json`의 사명 변경 별칭만 연결하며 신규 법인을 과거 법인과 임의로 합치지 않는다.

## 전속계약

최신 보고서 **주요계약 및 연구개발활동 → 주요 아티스트 전속계약** 표의 회사명·그룹·멤버를 rowspan까지 펼쳐 직접 추출한다. 등록 시점 현재 그룹 16개, 솔로 포함 20개 항목, 과거 종료 그룹 3개를 담았다. 이는 공시의 주요 명단이며 보고서 이후 데뷔 그룹이나 전 세계 음반·매니지먼트 계약 전체를 망라한 명단은 아니다.

계약 날짜·조건은 `manual/entertainment/hybe-contracts.json`을 수동 검토하여 보완한다. 공식 Weverse 공지와 회사 발언을 전달한 보도를 근거 유형으로 구분하고 상세에서 원문을 연결한다. 최초 체결일·재계약 결정/발표일·체결 완료 확인 보도·효력 개시·기존 만료일은 별개다. 데뷔일을 계약일로 넣거나 통상 7년을 확정 만료일로 계산하지 않는다.

- BTS: 2023-09-20 재계약 결정 발표와 09-25 체결 완료 확인 보도를 구분. 정확한 새 만료일 미공개.
- TXT: [2025-08-22 전원 재계약 공지](https://weverse.io/txt/notice/29620?hl=ko), 만료일 미공개.
- SEVENTEEN: [2021년 공식 공지](https://weverse.io/seventeen/notice/1502)와 [2026-07-13 두 번째 재계약 합의 발표](https://www.yna.co.kr/amp/view/AKR20260713104900005)를 구분. 복무 중 멤버 순차 체결 설명을 보존한다.
- NewJeans: 2022-04-21/2029-07-31은 어도어 공개 회신의 **기존 계약 날짜**다. 다니엘 해지 및 멤버별 상태가 다르므로 원년 전원에 대한 현재 만료일로 적용하지 않는다. 최신 공시는 4인 명단이다.
- ENHYPEN: [공식 공지](https://weverse.io/enhypen/notice/34159)의 희승 그룹 활동 종료와 레이블 내 솔로 활동을 구분. 그룹 탈퇴를 소속사 계약 종료로 쓰지 않는다.

수집일은 재무·명단 확인일이며 **계약 정보 검토일**과 별도로 표시한다. 날짜가 비공개인 경우 공란 대신 미공개를 보여 준다. 새로운 공시 명단 항목에 수동 검토 기록이 없으면 추가 검토 상태를 표시한다.

## 갱신과 검증

`python scripts/fetch_hybe_labels.py` / `--offline` / `--refresh`. `update-hybe-labels`는 기존 `update-entertainment` 성공 후 실행하고 일요일 KST 10:35에 별도 확인한다. 기존 4개 회사 수집과 분리된 검증·캐시·공개 파일을 사용한다. 실패하면 기존 재무 이력·명단·성공일을 보존한다. 원문 캐시는 `.cache/hybe-labels`에만 두고 공개 문서에는 API 키를 저장하지 않는다. 원문 표 구조와 메타데이터의 지문이 바뀌면 캐시를 다시 파싱한다.

`test_hybe_labels.py`는 실제 2023 사업/2026 반기 주석 발췌 표의 금액·단위·표 구조, 누적 차감 경계, 최초 법인 설립 전 매출 연결 금지, 명단·계약 근거, 실패 시 보존을 검사한다. JS 시험은 필터·기간·결측/0을 검사한다. 표는 40px 행을 유지하고 긴 이름은 말줄임/마우스 설명, 계약 근거는 표 밖 상세 패널로 제공한다.
