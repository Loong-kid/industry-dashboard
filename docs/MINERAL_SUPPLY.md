# 세계 국가별 광물 생산량 / 매장량

화면: 원자재 → `normal` / `구리` / `희토류`. 생산량·매장량은 각 광물의 가격 바로 아래에 표시한다.
별도 생산 / 매장량 탭이나 광종 선택기는 두지 않는다. 기존 `mineral_supply` 링크는 구리 탭으로 연결한다.

KOMIS 광물지도 https://www.komis.or.kr/Komis/MnrlMap/MnrlMap 의 공개 화면 요청을 사용한다.
원자료는 USGS Mineral Commodity Summaries다. 보장된 외부 OpenAPI로 부르지 않는다.

## 범위와 표시

- 2026-10-05 확인: 광종 목록 64개. 티타늄 일메나이트/루틸을 분리해 선택 항목 65개.
- 실제 국가별 수치가 있는 항목은 62개(61광종). 갈탄·루비듐·세슘은 미공개 안내.
- 대부분 2019~2025. 게르마늄은 2019~2020이며 최신 연도 경고를 표시한다.
- 광물별 가격과 국가별 생산량·매장량 연간 추이 두 카드, 국가 선택 칩, 전체 이력 표. 티타늄 일메나이트/루틸 두 생산품은 같은 티타늄 구간 아래에 각각 표시한다.
- 국가 비교표는 접이식이며 자체 연도 선택과 생산량/매장량 정렬을 제공한다. 공개 국가 합계 대비 비중이며 세계 전체 점유율이 아니다. 기타 국가를 만들어 넣거나 비공개 자료를 0으로 추정하지 않는다.
- `normal`에는 구리·희토류를 제외한 광물을 모두 모은다. 구리 LME 가격도 구리 탭에 함께 배치한다. 희토류 개별 원소 가격 14개와 전체 REO 생산량·매장량은 희토류 탭에 모으며, 전체 물량을 개별 원소의 물량으로 복제하지 않는다.
- 구리 생산량·매장량의 기본 선택 시리즈는 `전체 · 세계(USGS)`. 공식 보고서 `World total (rounded)` 행을 읽어 기타 국가까지 포함하며, 광산 구리 함유량(정련 생산 아님)이다. 2025 생산량 23,000,000톤(추정) / 매장량 980,000,000톤. 2019~2025 이력과 연도별 PDF 출처를 제공한다. 생산량은 다음 판의 과거 정정값을 우선하며, 매장량은 각 보고서 빈티지의 추정치를 해당 생산자료연도에 연결한다. 매장량의 12월31일 실측을 뜻하지 않는다.
- `전체 · 공개 국가 합계`도 별도 칩으로 제공한다. 2025 생산량 20,013,000톤 / 매장량 770,200,000톤. 기타 국가가 제외되며 포함 국가가 연도별 달라질 수 있다. 국가 비교표 비중의 분모에는 세계 전체나 합계 시리즈를 다시 더하지 않는다. 세계 전체와 국가별 숫자는 원자료 빈티지·반올림 차이가 있어 차이를 임의의 기타 국가 계열로 추정하지 않는다.
- 생산량에는 추정치가 포함된다. 매장량(Reserves)은 공표시점의 경제적 채굴 가능량 추정이며 자원량(Resources), 거래소 재고와 다르다. KOMIS 연도에 연결된 추정치이지 그해 12월 31일 실측을 뜻하지 않는다. 내부 차트 날짜는 연간 축 정렬용이고 화면에는 연도만 표시한다.

## 생산품·단위 검증

지도 프론트엔드 수량은 톤이다. `cdVal` kg/ton/k ton은 원래 USGS 장의 단위이며 이미 톤으로 변환된 `prdctnQuty`/`burudgQuty`에 다시 적용하면 1,000배 오류가 생긴다. 단위 코드/문자 조합 변경은 오류 처리한다.

USGS 2026 PDF https://pubs.usgs.gov/periodicals/mcs2026/mcs2026.pdf 와 대조:

| 비교값 | KOMIS 숫자 | USGS 원문 | 화면 기준 |
|---|---:|---:|---|
| 2025 칠레 구리 생산 | 5,300,000 | 5,300 천톤 | 5,300,000톤 · 구리 함유량 |
| 2025 중국 갈륨 생산 | 900 | 900,000kg | 900톤 · 저순도 1차 생산 |
| 2025 호주 리튬 생산 | 92,000 | 92,000톤 | 리튬 함유량, LCE 아님 |
| 2025 남아공 백금 생산 | 120 | 120,000kg | 120톤 · 백금 |
| 남아공 PGM 매장량 | 63,000 | 63,000,000kg | 63,000톤 · 백금족 전체 |

- 알루미늄 분류는 보크사이트 광산 생산·매장량이며 알루미늄 제련 생산량이 아니다.
- 마그네슘 분류는 마그네사이트 총중량이다. 마그네슘 금속 생산량과 다르다.
- 백금/팔라듐의 매장량은 같은 백금족(PGM) 전체 추정치를 각각 보여준다. 두 값을 더하지 않는다.
- 티타늄 일메나이트/루틸은 각각 정광의 TiO₂ 함유량. 미국 루틸이 일메나이트에 포함되는 등 원문 범위 주의.
- 희토류는 REO 함유량, 흑연은 천연 흑연, 질소는 암모니아 질소 함유량, 석회석 분류는 석회 생산.
- 원문 추정(e), 비공개(W), 미제공(NA), 부등호, 각주 등이 KOMIS 숫자 응답에 완전히 남지 않는다. 이력 전체를 원문과 독립 대조한 것은 아니다.
- 확인한 원문 차이: 2025 모잠비크 일메나이트 생산은 KOMIS 3,820,000톤, USGS 2026 PDF 1,900,000톤. KOMIS를 임의 수정하지 않고 해당 광종에 경고 표시. 숫자를 타 출처와 이어 붙이지 않는다.
- 값 0/null/NA/W는 관측치에서 제외한다. 진짜 0과 미공개의 원문 표기가 소실돼 둘을 구분할 수 없기 때문이다. 따라서 미공개나 실제 0도 차트에서는 공백이다.

## 수집과 실패 보존

`scripts/fetch_mineral_supply.py`, 검토된 광종·생산품 레지스트리 `scripts/mineral_supply_registry.json`.

1. 광종 목록을 레지스트리와 비교해 추가·삭제·이름 변경 시 검토 필요 오류.
2. `getMapMnrlCrtrYr`로 실제 제공 연도 확인.
3. `getListMapMnrlChartData`에서 국가/연도별 생산·매장량 조회. 티타늄에 `srchMnrkndSeCd=IM/RU` 적용.
4. 국가 코드, 연도, 단위, 중복, 음수/비유한 수치 검증. `TOTALPRDCTNQUTY`는 조회기간 전체 합이므로 특정 연도 세계 합계로 사용하지 않는다.
5. 전체 광종 검증 성공 후 공개 JSON 교체. 이전 공개 국가/연도가 사라지거나 최신 연도가 후퇴하면 기존 파일 유지. 반환된 날짜의 정정·철회는 반영, 조회 범위 이전 이력 보존.
6. 원응답은 `data/_mineral_supply/komis.json`, 화면 자료는 `data/commodities/comm_mineral_supply.json`.

기존 매일 KST 07:30 `update-data.yml`에 독립 수집 단계 연결. 자료는 연간이며 매일 새 공표·정정을 확인하는 방식이다. API 키 없음.

구리 세계 전체는 별도 `scripts/fetch_copper_world_supply.py`로 공식 USGS 전체 PDF의 구리 장을 읽는다. `data/commodities/comm_copper_world_supply.json`, `data/_mineral_supply/usgs_copper_world.json`에 숫자와 보고서·페이지 이력을 보존한다. 최초 MCS2020~2026, 이후 최신·직전 판을 재조회하고 새 판을 추가한다. 연초 최신 PDF가 404일 때만 직전 판으로 대체, 네트워크·스키마 오류는 기존 파일을 유지한다. 단위(천톤→톤), 광산/정련 컬럼, 자료연도, 구리 장, 기타 국가 포함 범위, 합계 크기, 이력 누락·최신후퇴를 검사한다. 매일 수집에 독립 단계 연결한다.
