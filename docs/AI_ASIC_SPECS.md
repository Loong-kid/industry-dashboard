# AI ASIC 사양표

반도체 > AI ASIC은 사용자 시트 `산업(AI_Infra_chip)_밸류에이션`의 **Chip!A1:AA67** 중 ASICs 구간(35~67행)을 옮긴 표다. GPU 구간은 기존 GPU 탭과 중복하지 않는다. 2026-10-25 읽기 전용으로 가져왔으며 사용자 시트는 수정하지 않았다.

- 원본: `manual/ai_asic_chip_sheet.json`. 실제 셀 값과 회사 공란·전망 표기 모두 보존한다. 필터용 회사 문맥은 앞선 회사 구간을 사용하되 Maia 100의 소속은 Microsoft 공식 발표로 교정한다.
- 보완: `manual/ai_asic_supplements.json`. 각 셀에 원본 행·제품명·공식 URL·확인일·설명을 연결한다. Ironwood 명칭, Trainium3 2025-12-02 GA/144 GB, MTIA 날짜·용량, Maia 날짜·사양 등을 확인했다. 원본과 다른 값은 메모·상세에서 원본을 함께 보여준다.
- 재생성: `python scripts/aggregate_ai_asic_specs.py`. 표는 수동 검토 스냅샷이며 실시간 자동 동기화가 아니다. 다른 **AI ASIC** 시트는 이번 데이터의 출처로 사용하지 않았다.
- 설계 협력사는 원본 주장이다. Broadcom·Marvell·Alchip·GUC·MediaTek을 제조 파운드리로 추정하지 않는다. 제조 파운드리는 공식 확인된 셀만 표시한다.
- F 표시는 원본 전망이다. 날짜가 지났어도 출시 확인으로 승격하지 않는다. 날짜 열은 공개일·정식 제공일·원본 시점을 옆 열에서 구분한다.
- TPU v5의 16/96은 합쳐진 원본 행이며 단일 칩 용량 범위가 아니다. 불확실한 로드맵명·공정·협력사·적층 수를 확정 사실로 취급하지 않는다.
- GB와 GiB, 칩 1개와 보드·Pod·서버·랙 합계를 구분한다. Trainium3 공식 공지의 GB 표기를 유지하며 Neuron 문서의 GiB와 단위 표기가 다름을 셀 메모에 남긴다. 정밀도·희소성이 다른 성능을 하나의 숫자로 정렬하지 않는다.

UI는 기존 GPU/메모리 표를 재사용한다. 제품명 고정, 40px 행, 기업·구분·검색·열 보기, 원본 보기, 마우스 메모, 오른쪽 상세와 실제 셀 좌표를 제공한다.

검증: `test_ai_asic_specs.py`, `verify_ai_asic_specs_ui.py` 및 메모리·GPU·반도체 탐색 회귀 테스트.
