# 태양광 기업 실적

태양광을 주력으로 하는 미국 상장 운영기업 8곳의 SEC 연결 공시를 추적한다. 미국·캐나다·이스라엘·중국계 기업을 포함하지만 세계 전체 제조사 목록이나 매출 순위가 아니다. ETF·주가·출하량을 실적에 섞지 않는다.

| 분야 | 기업 | 연결 범위 |
| --- | --- | --- |
| 모듈·통합 제조 | First Solar (FSLR) | CdTe 박막 모듈, 과거 시스템·발전 프로젝트 |
| 모듈·통합 제조 | Canadian Solar (CSIQ) | 모듈·ESS·Recurrent Energy 개발·발전 |
| 모듈·통합 제조 | JinkoSolar Holding (JKS) | 모듈·셀 등 Holding 연결, 중국 상장 자회사와 구분 |
| 인버터·에너지 관리 | Enphase (ENPH) | 마이크로인버터·배터리·에너지 관리 |
| 인버터·에너지 관리 | SolarEdge (SEDG) | 인버터·옵티마이저·배터리와 과거 비태양광 사업 |
| 추적기·발전 설비 | Nextpower, 옛 Nextracker (NXT) | 추적기·전기 설비·발전소 기술 |
| 추적기·발전 설비 | Array Technologies (ARRY) | 추적기·제어 시스템 및 연결 사업 |
| 폴리실리콘 소재 | Daqo New Energy (DQ) | DQ 연결 폴리실리콘 사업, 중국 상장 자회사와 구분 |

각 회사의 공식 IR 링크와 포함 범위는 `manual/solar/companies.json`에 보존한다. 초기 선정은 제조·전력변환·추적기·소재를 비교하고 장기 공개 실적을 확보할 수 있는 기업을 기준으로 했다. LONGi·Trina·Sungrow 등 중국 본토 상장사와 한화솔루션 등은 이번 등록 범위에 포함하지 않는다.

## 데이터와 기간

매출·영업손익은 연결 GAAP 실적, 순손익은 지배주주 귀속 실적이다. 비GAAP 조정 이익·EBITDA·수주·가이던스를 대입하지 않는다. 인수·매각·손상·세액공제와 지분 구조 변경을 포함하므로 회사 간 순수 태양광 매출이나 유기적 성장률로 합산하지 않는다.

미국 기업은 SEC Company Facts와 submissions를 대조한다. 2014년 이후 가용 기간을 수집하며 상장 전 운영기업 공시도 포함한다. 4분기 보완은 같은 회계연도·같은 태그의 연간 누적에서 9개월을 빼는 방식이다. 연간을 4로 나누지 않는다. First Solar의 과거 매출 태그 전환은 별도의 같은 태그 차분으로 보완한다. Enphase의 영업손익 소계 태그가 없는 과거 기간은 동일 공시·동일 기간의 매출총이익에서 영업비용을 뺀다.

SolarEdge는 2016년 6월 결산 이후 2016년 7~12월 6개월 전환기가 있다. 이 실적은 `전환기 6개월` 보기로 분리하고 일반 연간에 포함하지 않는다. Nextpower는 3월 말 52/53주 회계연도의 실제 보고 종료일을 유지한다.

외국 발행사 Canadian Solar·JinkoSolar·Daqo는 SEC 20-F의 실제 연간 실적과 SEC 6-K에 첨부된 분기 실적 발표문의 GAAP 연결 손익계산서를 수집한다. 셀의 colspan에 맞춰 날짜·통화 열을 연결하고 연결 매출·영업손익·회사 귀속 순손익이 모두 일치하는 표만 사용한다. 부분 매출, 편의상 USD 열, 조정 손익 표와 요약 표를 제외한다. 알 수 없는 새로운 표는 기존 성공 이력을 유지하고 검토 상태를 표시한다. 각 포인트에 실제 공시 URL·제출일·표 번호·행 이름을 보존한다.

JinkoSolar의 기본은 USD 백만이며, CNY 원자료는 금액·표·차트 메모 및 원통화 보기에서 확인한다. 공시의 편의상 기말 환율 USD를 장기 시계열에 이어 붙이지 않고 해당 보고기간의 ECB 일별 CNY/USD 평균환율로 변환한다. 다른 7개사는 USD 원자료를 그대로 사용한다. 환율 미확보·실적 미확보는 0이 아닌 결측이며 선을 끊는다.

각 기간에서 확보한 최신 공시를 적용한다. JinkoSolar·Daqo 등의 과거 연간은 사업 분리·중단사업 재분류를 반영해 재작성된 값일 수 있어 당시 분기 합계와 다를 수 있다. 분기 실적을 연간에 비례 배분하거나 임의 수정하지 않는다. 원문·제출일을 통해 비교 범위를 확인한다.

## 갱신과 재현

`update-solar.yml`은 매일 KST 09:35에 실행한다. 새 SEC 분기·연간 공시와 마지막 확인일 이후의 6-K 첨부를 읽는다. 일일 실행 시 과거 모든 발표문을 다시 다운로드하지 않으며, SEC facts가 수정된 실제 연간과 새 발표문의 비교기간도 반영한다. 출처별 실패 시 직전 성공 이력을 보존한다. 갱신 버튼은 같은 워크플로를 실행한다.

```sh
python scripts/fetch_solar.py
python -m unittest discover -s scripts -p test_solar.py -v
```

`--bootstrap`은 과거 SEC 6-K를 조사하는 최초 이식 옵션이다. 원본 응답은 커밋하지 않는 `.cache/solar/`에만 저장한다. `--offline --bootstrap`은 확보된 캐시로 초기 이력을 재현한다. 공개 `state.json`은 공시별 정규화 관측과 출처를, `fx.json`은 보고기간 환율을 보존한다. 일일 자동 커밋은 `data/solar/`만 변경한다.
