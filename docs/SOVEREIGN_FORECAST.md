# 국가별 부채·금리 전망 구간 표시

- 대상: IMF 정부부채/GDP, 정부부채 규모, GDP, 재정수지/GDP의 네 차트.
- `fetch_sovereign.py`가 기존 분류 기준인 당해연도 시작일을 `forecast_from`으로 저장한다. 현재 파일은 2026-01-01부터 IMF 전망으로 표시한다. 국가별 IMF 확정 실적 종료연도를 새로 판정하는 변경은 아니다. 이전 연도에도 추정치가 포함될 수 있어 범례는 **실적·추정**이다.
- 전망선은 Chart.js `segment.borderDash`의 `[6, 4]` 패턴으로 그린다. 마지막 이전 관측치에서 첫 전망값으로 연결되는 구간도 점선이다. 국가별 색상·칩·시리즈는 유지한다.
- 범례에 실선/점선과 전망 시작연도를 표시한다. 전망값의 카드 기준연도·툴팁·표에도 전망 표시를 붙인다. 연간 자료는 연도만 표시한다.
- BIS 분기 부채 및 국채금리는 전망 표식을 넣지 않는다. 기존 데이터 공백 점선 기능과 함께 설정되면 전망 점선이 우선한다.
- 가격·비율·GDP 값 및 자료일·수집일은 수정하지 않는다. 다음 자동 수집에서도 구분 정보가 유지되도록 수집기와 공개 JSON을 함께 갱신한다.

검증:

```powershell
python -m unittest discover -s scripts -p test_sovereign_forecast.py
node scripts/test_sovereign_forecast.cjs
```

실제 Chrome/Chart.js에서도 실선·점선 세그먼트, 첫 전망연도 호버, 기간 선택, 모바일 및 다크 모드를 확인한다.
