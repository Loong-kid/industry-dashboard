# 양산 프리미엄 (2026-10-02)

사용자 요청에 따라 공개 페이지에서 수집한 자료를 원자재 > 구리 탭에 반영했다. 자동 갱신은 아직 설정하지 않았다.

- Mysteel 중국어 일일 가격표: 창고증권·선하증권 각각 화법동·습법동. 원문 최저·최고·중간값, ETA/QP 조건, 날짜와 URL을 각 JSON의 source_records에 보존한다.
- SMM 공개 가격 목록: 2026-09-30 창고증권 평균 119, 선하증권 평균 114 USD/톤. Mysteel과 섞지 않고 별도 참고 카드로 표시한다.
- 과거 수집 범위: 2025-02-18~2026-09-30 중 353개 날짜, 1,412개 원자료. 산술 중간값 불일치 28개는 시계열에서 제외하여 1,384개를 반영했다. 음수 프리미엄은 허용한다.
- 재요청: 과거 제외 기사 90개를 같은 공개 URL로 1초 간격 재확인했다. 44개 기사 복구, 날짜 불일치 45개·가격 범위 오류 1개는 계속 제외했다. 로그인·프록시·접근 제한 우회는 사용하지 않았다.
- 누락은 보간하거나 0으로 채우지 않는다. 사용자가 요청한 연속 그래프를 위해 관측값을 선으로 연결한다. 7일 초과 관측 간격은 점선으로 표시한다. 공백에는 휴일도 섞이므로 모든 공백이 수집 실패는 아니다.
- 원문 수치는 제공처의 공시값이며 독립된 다른 출처와 모든 날짜를 대조한 것은 아니다. 계약 조건과 등급이 바뀌는 점을 해석에 고려해야 한다.

변환: `python scripts/import_yangshan.py local-private/yangshan`. 이 명령은 저장된 파일만 읽고 네트워크를 사용하지 않는다. 로컬 원자료 디렉터리는 Git에서 제외되어 있으며, 배포에는 검증된 카드 JSON만 포함한다. 수집기를 일별 워크플로에 연결하지 않았다.
