# 양산 프리미엄 (2026-10-02)

## 자동 갱신 추가

- `fetch_yangshan.py`를 기존 update-data의 매일 KST 07:30 일정에 연결했다. SMM 공개 목록 1회, Mysteel 목록 1회와 최신 기사 2개 및 새 기사만 읽는다(기사 최대 8개, 요청 간 1초). 대량 과거 수집을 반복하지 않는다.
- SMM은 별도 일간 시계열로 누적한다. Mysteel은 기존 4개 시계열을 유지하며 접근 가능한 경우만 업데이트한다. 제공처 값으로 다른 제공처의 공백을 메우지 않는다.
- 실제 실행에서 SMM은 정상 수집, Mysteel 목록은 HTTP 200이지만 보안 확인 화면을 반환했다. 빈 자료를 성공으로 처리하지 않고 카드에 실패 상태를 표시한다. 로그인·프록시·접근 제한 우회나 자동 재시도는 없다.
- 신규 자료 없으면 같은 기준일을 유지한다. 관측값뿐 아니라 최저·최고가 수정도 감지하여 검토 전 덮어쓰지 않는다. 날짜·단위·중간값 불일치, 과거 날짜로 역행하는 응답은 실패로 처리한다.
- 한 제공처 실패가 다른 제공처를 막지 않는다. 실패 시 기존 series/source_records/updated/fetched는 보존하고 확인 시도 상태만 남긴다. 정상 확인 시 fetched는 한국 날짜로 갱신하되 updated는 실제 관측일이다.
- GitHub 기본 토큰의 자동 커밋은 Pages 빌드를 일으키지 않으므로 `publish-data.yml`이 update-data 완료 후 최신 main의 index.html/assets/data만 배포한다. 원자료·개인 작업 경로는 배포 묶음에 넣지 않는다.
- `test_yangshan_refresh.py`로 음수 가격·날짜 검증·충돌 보호·기존 이력 유지·한 제공처 실패 시 다른 제공처 정상 반영을 확인한다.

아래는 최초 일회 수집·배포 당시 기록이다.

사용자 요청에 따라 공개 페이지에서 수집한 자료를 원자재 > 구리 탭에 반영했다. 자동 갱신은 아직 설정하지 않았다.

- Mysteel 중국어 일일 가격표: 창고증권·선하증권 각각 화법동·습법동. 원문 최저·최고·중간값, ETA/QP 조건, 날짜와 URL을 각 JSON의 source_records에 보존한다.
- SMM 공개 가격 목록: 2026-09-30 창고증권 평균 119, 선하증권 평균 114 USD/톤. Mysteel과 섞지 않고 별도 참고 카드로 표시한다.
- 과거 수집 범위: 2025-02-18~2026-09-30 중 353개 날짜, 1,412개 원자료. 산술 중간값 불일치 28개는 시계열에서 제외하여 1,384개를 반영했다. 음수 프리미엄은 허용한다.
- 재요청: 과거 제외 기사 90개를 같은 공개 URL로 1초 간격 재확인했다. 44개 기사 복구, 날짜 불일치 45개·가격 범위 오류 1개는 계속 제외했다. 로그인·프록시·접근 제한 우회는 사용하지 않았다.
- 누락은 보간하거나 0으로 채우지 않는다. 사용자가 요청한 연속 그래프를 위해 관측값을 선으로 연결한다. 7일 초과 관측 간격은 점선으로 표시한다. 공백에는 휴일도 섞이므로 모든 공백이 수집 실패는 아니다.
- 원문 수치는 제공처의 공시값이며 독립된 다른 출처와 모든 날짜를 대조한 것은 아니다. 계약 조건과 등급이 바뀌는 점을 해석에 고려해야 한다.

변환: `python scripts/import_yangshan.py local-private/yangshan`. 이 명령은 저장된 파일만 읽고 네트워크를 사용하지 않는다. 로컬 원자료 디렉터리는 Git에서 제외되어 있으며, 배포에는 검증된 카드 JSON만 포함한다. 수집기를 일별 워크플로에 연결하지 않았다.
