# CPU·일반 GPU 발표일과 출시일

2026-10-25 기준. CPU 기본 비교표는 기존 시트의 G열(출시일)을 제품명 다음에 표시한다. F열 발표일은 전체 사양·상세에서 유지한다. CPU 날짜 자체를 이번 작업에서 새로 검증한 것은 아니다.

일반 GPU는 `manual/gpu_release_dates.json`에서 제품별 발표일과 출시 시기를 별도로 관리한다. 공식 제조사·OEM 자료에서 40개 GPU의 출시 시기, 37개 GPU의 제품·상용 출시 발표일을 확인했다. Iris 6100, HD 4600, HD 3000은 공식 그래픽 출시월만 표시하고 별도의 제품 발표일은 미확인으로 남겼다.

- 기본 보기: 제품명 다음 출시일. 전체 사양·상세 및 ‘발표·출시일’ 보기에 두 날짜와 출처를 제공한다.
- 원본 시트 E열의 합쳐진 날짜는 ‘발표/출시일 · 시트 원본’으로 보존한다. 새 날짜의 근거로 자동 복제하지 않는다. ‘시트 원본’ 모드에서는 보완 날짜를 숨긴다.
- 내장 GPU는 독립 소매 제품이 아니므로 탑재 플랫폼 제품군·대표 CPU·제조사 GPU 출시월 중 확인 가능한 기준을 셀 메모에 명시한다. 제품군의 첫 시스템 일정은 해당 행에 열거된 모든 SKU의 개별 판매일을 뜻하지 않는다.
- 발표일은 공식 제품·상용 출시 공지 기준이다. A750/A770은 2022-09-29 가격·출시 공지, RX 9070 XT는 2025-02-28 상세 제품·출시 공지이며 최초 티저·아키텍처 예고 날짜와 구분한다.
- 제조사가 출시 예정 시기만 안내한 값은 표에도 ‘안내’를 붙인다. `status=scheduled`이며 실제 OEM별 판매일을 확정한 값이 아니다. Intel 200H, A380 중국 OEM, RTX 5090 Laptop, Radeon 8060S·680M에 적용한다.
- RTX 5070 데스크톱은 최초 예정월 대신 2025-03-05 판매 공지를 사용한다. RTX 5070 Laptop은 2025년 판매만 OEM 자료로 확인했으며 첫 판매 월·일은 미확인이다. 2025-04 예정 안내를 실제 판매일로 사용하지 않는다.
- Arc A770M/A370M은 ARK의 칩 출시 분기를 유지한다. 분기·월·연도에 임의의 날짜를 붙이지 않는다. 날짜 정렬은 해당 기간의 시작 순서일 뿐 실판매일 추정이 아니다.
- Radeon 890M은 ASUS의 2024년 7월 탑재 시스템 판매 공지를 사용한다. 현재 AMD HX 370 사양 페이지의 2025년 출시 표기는 당시 판매 공지와 일치하지 않아 채택하지 않았다.

`scripts/aggregate_gpu_specs.py`는 출처, 날짜 형식·정밀도, 이벤트 종류, 행별 제품 대응 및 중복을 검증한다. 날짜가 없는 구형 제품의 발표일은 상세 메모에 미확인 사유를 표시한다. `scripts/test_gpu_specs.py`는 서로 다른 발표/판매 날짜와 원본 보존을 확인하고, CPU/GPU UI 검증은 4개 화면 너비에서 출시일 열·날짜 정렬·고정 행 높이를 확인한다.

재생성:

```powershell
python scripts/aggregate_gpu_specs.py
python scripts/aggregate_cpu_specs.py
```

NVIDIA AI 가속기 표의 원본 ‘발표/출시일’은 이번 일반 GPU 조사 범위에 포함하지 않는다.
