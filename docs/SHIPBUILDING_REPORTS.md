9월 11일 파일 이후 신규 8개 보고서를 반영했으며, 최종 발간본은 2026-11-16, 최종 관측일은 2026-11-13입니다. 보고서가 없는 11월 20일 주간 값을 생성하지 않습니다.

조선 시장의 신조선가지수·선종별 신조선가·연초 누적 발주량·중고선가 5개 문서와 같은 보고서의 해운 운임·ClarkSea 4개 문서를 갱신합니다. 국내 4사 DART 수주·인도·매출 추정과 개별 기업 실적은 이 보고서의 시장 통계와 별도입니다.

중고선가지수는 원문 표의 Tanker / Bulk / Container / 종합을 각각 별도 시리즈로 구분했습니다. 기존 파서가 Container 행을 벌커 값에 덮어쓴 오류를 고치고, 폴더의 107개 보고서로 과거 벌커 지수를 재추출했습니다. 선령·크기가 서로 다른 컨테이너 개별 중고선가는 계속 추출 대상에서 제외하지만, 명시적으로 공표된 컨테이너 지수는 별도 계열로 보존합니다.

실행:

```powershell
python scripts/extract_shinyoung.py
python scripts/extract_shinyoung.py --pdf-dir "C:\Users\wkoro\Desktop\증권사레포트\조선"
```

기본 경로는 현재 사용자 바탕화면입니다. 원본 PDF는 수정하거나 공개 저장소에 올리지 않습니다. 원본 첫 페이지의 실제 발간일·파일명·SHA256은 `manual/shinyoung/reports.json`에 남기고, 각 지표의 `latest_report`와 설명에 마지막 보고서를 표시합니다. 파일명의 날짜가 원문 발간일과 다르면 원문의 날짜를 사용합니다.

첫 페이지 상단이 이미지인 과거 7개 보고서는 렌더링한 원문을 직접 확인했습니다. 해당 날짜는 `manual/shinyoung/report_date_reviews.json`에 원본 SHA256과 함께 기록하며, 파일 내용이 바뀌면 이 검토값을 적용하지 않습니다.

관측일은 표 헤더의 주간 날짜를 사용하며, JSON의 `updated`는 최신 관측일, `fetched`는 추출 실행일입니다. 두 주간 값만 읽으며 이전 연도의 연말 값·평균값은 주간 값으로 추가하지 않습니다. 일부 표가 빠진 보고서는 전체 저장을 중단하여 부분 추출 결과로 기존 이력을 덮어쓰지 않습니다.

원문의 날짜 오자 `7-Jun--2024` 및 `6-S-2024`를 처리합니다. 후자는 같은 보고서의 다른 세 표에 `6-Sep-2024`가 명시되어 있습니다.
