## 화면

메모리 탭 상단에 두 표를 배치하고 기존 삼성전자·SK하이닉스·Micron 실적 9개 그래프를 유지했다. CPU/GPU와 같은 40px 행, 제품명 고정, 표 내부 가로 스크롤, 마우스 메모, 오른쪽 상세를 사용한다. 기업·행 구분·검색·열 보기·원본/보완 전환을 제공한다. 사양은 시점별 검토 스냅샷이며 실적 갱신 버튼이 시트 사양을 다시 가져오지는 않는다.

DDR은 18개 원본 행 중 SDRAM·DDR·DDR2·DDR3·DDR4·DDR5의 6개 세대가 기본이다. 12개 공정 행은 ‘공정 메모’ 필터와 ‘공정·셀 구조’ 보기에서 확인한다. 인접 세대명은 문맥이며 특정 DDR에만 사용하는 공정이라고 단정하지 않는다. 9·10행 E열의 26nm/20nm는 전송 속도가 아니라 공정 치수로 매핑한다.

HBM은 16개 원본 행 중 15개 제품·공개 사양 행이 기본이다. 삼성 HBM 자리표시는 ‘시트 메모’ 또는 전체 필터에 남긴다. HBM4E는 공식 제품군의 공개 최대 사양을 보완하되 미확인 코드명·고객 출하를 확정하지 않는다. 생략된 회사는 앞선 회사 구간을 필터 문맥으로 사용하고, 보완 셀은 시트 문맥 출처로 표시한다.

## 비교·보완 기준

- DDR4·DDR5 속도는 Micron 기술 백서의 대표 범위를 사용한다. 최신 모든 제품·OC 최고값이 아니다. Prefetch, Die 밀도를 추가하고 64-bit 기준 이론 대역폭을 구분한다. DDR5는 32-bit 서브채널 2개 합계이다. DDR3의 대역폭은 시트 속도로 계산했으며 실측값이 아니다.
- 모듈 용량 GB, Die 용량 Gb, HBM 스택 용량 GB를 구분한다. HBM 원본 J열에 단위 없이 적힌 8/16/12/24/18/36은 임의로 Gb를 붙이지 않고 별도 원본 열에 보존한다. 공식 근거나 계산 조건이 있는 Die 밀도만 비교 열에 넣는다.
- HBM 속도는 핀당 Gb/s, 대역폭은 스택 1개당 GB/s이다. GPU 전체 HBM 합계를 가져오지 않는다. ‘최대’, ‘초과’, ‘계산’, ‘개발’ 표기를 유지한다. 수치 정렬은 표기된 첫 숫자이며 구간·최대값의 실측 순위를 의미하지 않는다.
- SK하이닉스 HBM4 원본 165 GB/s는 2025년 12H 샘플 발표의 >2 TB/s로 검토 표시했다. 2025-09-12는 개발 완료·양산 준비 공지로, 고객 출하 완료일로 표시하지 않는다.
- SK하이닉스 HBM3E는 2024-09-26의 36GB 12H 프로파일을 명시하고, 9.6 Gb/s × 1024 / 8의 1228.8 GB/s는 계산값으로 표시한다. 이전 8H·후속 16H를 같은 용량으로 섞지 않는다.
- 삼성 Aquabolt는 2018년 8GB 8H 프로파일, Flashbolt는 2020년 16GB 8H 프로파일이다. Flashbolt 4H는 시트 구성과 16Gb Die를 가정한 계산임을 표시하고 해당 4H SKU의 공식 존재·공급을 확정하지 않는다.
- 삼성 HBM3E 속도·대역폭은 현재 공식 제품 페이지의 최대9.2 Gb/s·최대1180 GB/s를 사용한다. 이정표에는 2023년 Shinebolt 공개와 2024년 12H 개발 공지를 구분한다. 과거 개발 최대치 9.8 Gb/s·1280 GB/s는 현재 제품 사양과 구분해 메모에 남겼다. 8H/12H의 Die 24Gb는 공식 용량·적층 수에서 역산한 값이다.
- 삼성 HBM4E는 공식 제품군 페이지의 최대64GB·최대16H·최대16 Gb/s·2048 I/O이며 4096 GB/s는 이론 계산값이다. 원본 flamebolt 코드명·개별 SKU·실제 고객 출하는 확인하지 않았다. 날짜가 없는 제품 페이지로 최초 발표일을 추정하지 않는다.
- 삼성 HBM4는 2026년 양산·출하 공지의 12H 24~36GB·1c DRAM·4nm logic 기준이다. 16H 48GB 확장 계획을 12H에 섞지 않는다. 최대3300 GB/s는 최대13 Gb/s 조건의 반올림 값이며 11.7 Gb/s 조건과 동일한 대역폭이 아니다.
- TSV·셀 구조·패키지 치수 등 공개 근거가 부족한 미세 구조 값은 원본 메모로 유지했다. 55×55 등 원본 패키지 치수는 대상·단위를 확정하지 않았으며 HBM 스택 실측 면적으로 표시하지 않는다.
