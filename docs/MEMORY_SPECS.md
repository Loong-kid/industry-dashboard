## 화면

메모리 탭 상단에 두 표를 배치하고 기존 삼성전자·SK하이닉스·Micron 실적 9개 그래프를 유지했다. CPU/GPU와 같은 40px 행, 제품명 고정, 표 내부 가로 스크롤, 마우스 메모, 오른쪽 상세를 사용한다. 기업·행 구분·검색·열 보기·원본/보완 전환을 제공한다. 사양은 시점별 검토 스냅샷이며 실적 갱신 버튼이 시트 사양을 다시 가져오지는 않는다.

DDR 기본은 회사별 21개 제품·제품군 비교다. 회사·제품/공정·DDR 규격·Die 용량·속도·전압·64-bit 환산 대역폭·이정표를 함께 표시한다. 부품 번호·칩 I/O·자료 범위도 전체 보기와 상세에서 확인한다. 회사 필터는 삼성전자·SK하이닉스·CXMT·Micron을 구분한다.

18개 원본 행은 모두 유지했다. ‘세대 비교 · 시트’를 선택하면 SDRAM·DDR~DDR5 6개 세대, ‘공정·셀 구조’를 선택하면 12개 공정 메모로 전환한다. 인접 세대명은 문맥이며 특정 DDR에만 사용하는 공정이라고 단정하지 않는다. 9·10행 E열의 26nm/20nm는 전송 속도가 아니라 공정 치수로 매핑한다. 원본 Hynix 표기는 필터 문맥에서 SK하이닉스로 통일하되 원본 셀은 보존한다. ‘시트 원본’ 모드는 회사별 추가 행을 제외하고 원본 18개 행을 보여준다.

HBM은 16개 원본 행 중 15개 제품·공개 사양 행이 기본이다. 삼성 HBM 자리표시는 ‘시트 메모’ 또는 전체 필터에 남긴다. HBM4E는 공식 제품군의 공개 최대 사양을 보완하되 미확인 코드명·고객 출하를 확정하지 않는다. 생략된 회사는 앞선 회사 구간을 필터 문맥으로 사용하고, 보완 셀은 시트 문맥 출처로 표시한다.

## 비교·보완 기준

- 회사별 행은 각 출처의 발표 시점·데이터시트 프로파일이다. 전 SKU를 망라하거나 현재 양산·재고 상태를 뜻하지 않는다. 제품군의 최고 속도·지원 용량을 개별 SKU 조합으로 확정하지 않으며, 속도나 전압이 명시되지 않은 프로파일은 빈칸으로 둔다. 표의 1a·1b·1c·1α·1γ는 회사 고유 표기이며 타사의 동일 nm로 환산하지 않는다.
- 삼성은 DDR3 4Gb 20nm, DDR4 8Gb 20nm/1x/1y, DDR5 14nm 제품군·16Gb/32Gb 12nm를 구분했다. 14nm 공지의 24Gb 확장 계획은 실제 Die 용량으로 넣지 않았고, 16Gb의 7200 MT/s를 32Gb에 복사하지 않았다.
- SK하이닉스는 DDR4 8Gb 1y·16Gb 1z, DDR5 16Gb 1y·24Gb 1a·1b 검증 프로파일·16Gb 1c·32Gb 1b를 구분했다. 24Gb의 속도 개선율에서 절대 속도를 역산하지 않는다. 256GB RDIMM 인증 공지의 기반 Die는 32Gb이며 모듈 GB와 구분한다.
- CXMT DDR5는 공식 제품군의 16/24Gb·최대8000 MT/s와 2025-11-23 공개 이정표를 사용한다. 미공개 공정·전압은 채우지 않는다. DDR4는 공식 연혁의 8Gb·2019년 양산/판매와 TechInsights의 직접 실물 분석 초록을 구분한다. 2x(22nm)·CXDQ3A8AM-CG는 분석 출처를 명시하며 다른 CXMT 제품에 적용하지 않는다. 분석 보고서 공개일을 출시일로 쓰지 않는다.
- Micron은 monolithic 8Gb DDR3L x16 -125, 16Gb DDR4 -062E 부품군, 1α DDR4 노드·제품군, DDR5 16/24/32Gb 제품군, 1γ 16Gb DDR5 9200을 구분했다. 같은 접두어의 2×4Gb TwinDie 문서와 8Gb monolithic 문서를 섞지 않는다. 공정 노드가 명시되지 않은 데이터시트에 다른 제품의 노드를 붙이지 않는다.
- 회사별 대역폭은 공개 MT/s × 가정한 64-bit 폭 ÷ 8 ÷ 1000의 환산값이다. 칩 I/O 폭이 확인된 단일 변형만 별도 칩 이론 대역폭을 계산한다. 예를 들어 Micron DDR3L x16 1600은 칩 3.2 GB/s, 64-bit 환산 12.8 GB/s로 서로 다르다. DDR5 1γ 9200의 73.6 GB/s는 환산값이며 DRAM 칩 단독 대역폭·실측값이 아니다.
- 시트 세대 비교의 DDR4·DDR5 보완 속도는 Micron 기술 백서의 대표 범위를 사용한다. 최신 모든 제품·OC 최고값이 아니다. Prefetch, Die 밀도를 추가하고 64-bit 기준 이론 대역폭을 구분한다. DDR5는 32-bit 서브채널 2개 합계이다. DDR3의 대역폭은 시트 속도로 계산했으며 실측값이 아니다.
- 모듈 용량 GB, Die 용량 Gb, HBM 스택 용량 GB를 구분한다. HBM 원본 J열에 단위 없이 적힌 8/16/12/24/18/36은 임의로 Gb를 붙이지 않고 별도 원본 열에 보존한다. 공식 근거나 계산 조건이 있는 Die 밀도만 비교 열에 넣는다.
- HBM 속도는 핀당 Gb/s, 대역폭은 스택 1개당 GB/s이다. GPU 전체 HBM 합계를 가져오지 않는다. ‘최대’, ‘초과’, ‘계산’, ‘개발’ 표기를 유지한다. 수치 정렬은 표기된 첫 숫자이며 구간·최대값의 실측 순위를 의미하지 않는다.
- SK하이닉스 HBM4 원본 165 GB/s는 2025년 12H 샘플 발표의 >2 TB/s로 검토 표시했다. 2025-09-12는 개발 완료·양산 준비 공지로, 고객 출하 완료일로 표시하지 않는다.
- SK하이닉스 HBM3E는 2024-09-26의 36GB 12H 프로파일을 명시하고, 9.6 Gb/s × 1024 / 8의 1228.8 GB/s는 계산값으로 표시한다. 이전 8H·후속 16H를 같은 용량으로 섞지 않는다.
- 삼성 Aquabolt는 2018년 8GB 8H 프로파일, Flashbolt는 2020년 16GB 8H 프로파일이다. Flashbolt 4H는 시트 구성과 16Gb Die를 가정한 계산임을 표시하고 해당 4H SKU의 공식 존재·공급을 확정하지 않는다.
- 삼성 HBM3E 속도·대역폭은 현재 공식 제품 페이지의 최대9.2 Gb/s·최대1180 GB/s를 사용한다. 이정표에는 2023년 Shinebolt 공개와 2024년 12H 개발 공지를 구분한다. 과거 개발 최대치 9.8 Gb/s·1280 GB/s는 현재 제품 사양과 구분해 메모에 남겼다. 8H/12H의 Die 24Gb는 공식 용량·적층 수에서 역산한 값이다.
- 삼성 HBM4E는 공식 제품군 페이지의 최대64GB·최대16H·최대16 Gb/s·2048 I/O이며 4096 GB/s는 이론 계산값이다. 원본 flamebolt 코드명·개별 SKU·실제 고객 출하는 확인하지 않았다. 날짜가 없는 제품 페이지로 최초 발표일을 추정하지 않는다.
- 삼성 HBM4는 2026년 양산·출하 공지의 12H 24~36GB·1c DRAM·4nm logic 기준이다. 16H 48GB 확장 계획을 12H에 섞지 않는다. 최대3300 GB/s는 최대13 Gb/s 조건의 반올림 값이며 11.7 Gb/s 조건과 동일한 대역폭이 아니다.
- TSV·셀 구조·패키지 치수 등 공개 근거가 부족한 미세 구조 값은 원본 메모로 유지했다. 55×55 등 원본 패키지 치수는 대상·단위를 확정하지 않았으며 HBM 스택 실측 면적으로 표시하지 않는다.
