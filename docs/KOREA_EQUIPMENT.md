# 국내 반도체 장비 비교군

2026-11-03 네이버증권 시가총액 후보 22개사와 공식 제품·사업 자료를 대조해 장비 기업 10개사를 추가했다. 기존 한미반도체는 중복 추가하지 않아 국내 총 11개사, 기존 전체 요약 비교군과 합쳐 총 23개사다. 이 비교군은 모든 국내 상장사의 공식 시총 순위가 아니며, 선정 이후 시가총액은 변한다. 선정 시점의 시장 표기·시가총액·원문 링크·후보별 포함 여부는 `manual/korea-equipment/market-cap-selection.json`에 남긴다. 화면의 시총은 실시간 값과 구분한다.

| 분류 | 새 기업 | 기준 |
|---|---|---|
| 전공정 | 원익IPS·주성엔지니어링·유진테크·테스 | 증착·열처리·건식 세정 |
| 전공정 | HPSP·피에스케이 | 고압 수소 어닐링·PR 제거/건식 세정 |
| 전공정 + 패키징·후공정 | 이오테크닉스 | 전공정 레이저 어닐링과 후공정 마킹·그루빙·다이싱 |
| 패키징·후공정 | 피에스케이홀딩스 | Descum·Fluxless Reflow |
| 검사·계측 | 파크시스템스·고영 | AFM 나노계측 / 전자조립·첨단패키징 3D SPI·AOI 검사 |

한미반도체는 기존 HBM TC 본더·후공정 장비 분류를 유지한다. 테크윙의 핸들러·프로버는 테스트 공정 후보로 검토했지만 선정 시점 시총 상위권 10개 신규 기업 이후의 확장 대상으로 남긴다. 부품·소재·OSAT 서비스를 장비 제조사로 섞지 않는다. 이오테크닉스를 두 공정에 연결해도 전체 요약에는 한 번만 표시하며 전사 실적을 공정별 매출로 합산하지 않는다. 고영의 SMT 검사와 파크시스템스의 AFM, KLA의 웨이퍼 공정제어, ATE 전기 테스트를 같은 역할로 설명하지 않는다.

## 실적과 법인 이력

OpenDART 전체 계정 API에서 종목코드와 법인명을 동시에 검증하고, 연결을 우선하되 연결 미공시 기간은 별도를 표시한다. 기존 `ring_financial_sources`의 매출·영업손익·유형자산 취득 현금지출, 전기 비교표시, 누적 차감 로직을 재사용한다. 분기·완결 회계연도를 구분하고 미확인 분기는 0이나 연간의 1/4로 채우지 않는다.

원익IPS는 2016-04-01, 피에스케이는 2019-04-01에 분할 신설된 현재 법인부터 표시한다. 그 전의 원익홀딩스·피에스케이홀딩스 실적을 이어 붙이지 않는다. 첫 9개월 회계연도는 분할 후 기간이라고 명시하고, 4~6월 첫 3개월 현금지출은 존재하지 않는 1분기 누적을 차감하지 않는다. 피에스케이홀딩스는 분할 전후 사업 범위 변화와 별도 상장사 피에스케이를 구분한다.

일부 주성엔지니어링 공시의 항목별 유형자산 취득은 현금유출을 음수로 표시한다. 해당 회사로 한정해 취득 세부 항목 전체가 음수인 원문 열만 양수 지출로 정규화하고, 원문 부호를 `original_signed_inputs`에 보존한다. 실제 환급·순유입을 일괄 절댓값 처리하지 않으며 누적 차분이 음수인 미확인 구간은 공백으로 둔다. 유형자산 현금취득에는 무형자산·M&A·비현금 리스·고객사 설비투자를 넣지 않는다.

매출은 회사 전체 공시다. 디스플레이·태양광·PCB·연구장비·의료로봇·종속기업 등이 섞이는 기업은 제품별 분류와 전사 실적의 범위를 구분한다. 각 포인트의 DART 출처와 연결·별도, 합산 및 차감 근거를 표·집계 기준에 보존한다.

## 가격·밴드·갱신

새 기업 10개를 기존 반도체 주가·PER·PBR 시스템에 연결한다. 보고 실적 TTM EPS와 공시 BPS를 사용하며 예측·컨센서스는 제외한다. 상장 전 가격을 만들지 않고 기존 회사의 파일은 보존한다. 분할 반영 주가, 음수 이익/자본의 N/M, 돋보기 확대, 기간 선택, 지연 로딩은 기존 공통 기능을 사용한다.

국내 재무는 기존 `update-equipment.yml`의 별도 `korea` job에서 매일 08:30 KST에 확인하고, 주가·밴드는 기존 `update-semicon-valuation.yml`의 08:10 KST 갱신을 사용한다. 각 수집의 검증 실패가 다른 수집 job을 막지 않도록 분리한다. API 키는 기존 GitHub Secret만 사용하며 공개 파일·로그에 저장하지 않는다. 원문 조회 실패 시 마지막 성공 이력을 보존하고 상태를 표시한다.

```text
python scripts/fetch_korea_equipment.py --refresh --full-history
python scripts/fetch_korea_equipment.py --from-state
python -m unittest discover -s scripts -p test_korea_equipment.py -v
```
