# 국내 반도체 소부장 추가 기업

2026-11-18 검토. 단일 시장점유율 순위가 아니라 기존 대시보드에 부족한 공정·제품을 보완하는 20개 상장사를 먼저 선정했고, 사용자 지정 블로그에서 기존 기업을 제외한 8개사를 추가해 총 28개사를 다룬다. 회사 전체 실적을 특정 반도체 제품의 실적으로 해석하지 않는다.

| 세부탭 | 추가 기업 |
| --- | --- |
| 소재 → 공정 화학소재 | 솔브레인, 동진쎄미켐, 이엔에프테크놀로지, 한솔케미칼 |
| 소재 → 특수가스·전구체 | 원익머트리얼즈, 레이크머티리얼즈 |

| 부품 → 패키지기판 | 심텍, 대덕전자 |

장비 9개사는 장비 전체 요약에도 연결한다. 각 기업에 매출·영업이익·현금 CAPEX 차트 및 주가·실제 TTM PER·PBR을 연결했다. 밸류에이션은 기존 공통 수집기를 사용한다. 적자 PER이나 확인하지 못한 과거 EPS는 빈칸으로 남긴다.

## 재무 원본과 기간

- 출처는 OpenDART 정기보고서 전체 재무제표. 각 시계열 관측치에 실제 DART 접수번호, 공시일, 계정, 원문 기간, 연결/별도 및 차분 근거를 보관한다.
- 2015년부터 전체 원본을 수집하며, 원문에 있는 전기 비교열로 2014년 연간을 확보한다. 공개 원본이 없는 과거 분기는 보간하지 않는다.
- 연결을 우선하고 연결이 없는 기간에는 별도를 표시한다. 서로 다른 연결/별도 기준의 전년·전분기 증가율은 계산하지 않는다.
- 매출·영업이익은 실제 3개월 공시를 우선한다. 4분기는 같은 회계연도 연간−9개월로 계산한다.
- CAPEX는 현금흐름표의 유형자산 취득 현금지출이다. 무형자산·M&A·비현금 리스 등은 제외한다. 분기는 확인된 같은 범위 누적 현금지출의 차이이며, 누적 역전·불명확한 기간은 공백이다.
- 솔브레인(2020-07), 심텍(2015-07), 대덕전자(2020-05), 케이씨텍(2017-11)은 신설법인 시작을 구분한다. 짧은 첫 연도와 12개월 연도의 YoY를 비교하지 않는다. 대덕전자의 첫 2개월·케이씨텍의 첫 2개월을 일반 3개월 분기로 만들지 않는다.
- 레이크머티리얼즈·네오셈은 합병 이전 SPAC의 재무제표를 제외한다. 합병 이후 사업회사 공시에서 명시적으로 재작성된 비교기간은 포함한다. 주가도 사업회사 상장·합병 기준일부터 사용한다.
- 기업별 실제 확보 시작일은 화면의 사업·실적 표와 아래 개별 차트의 집계 기준에 표시한다.

## 제품·사업 매출 표

`manual/semicon-supplychain/business-mix.json`은 실제 DART 보고서의 주요 제품·사업별 매출 표를 확인한 스냅샷이다. 원문을 `scripts/collect_supplychain_business.py`로 열어 기간·단위·병합 셀을 확인했다. 스냅샷에 확인일과 정확한 원문 페이지를 연결한다.

매출구성 표의 1~9월 **누적** 금액과 아래 차트의 **분기 단독** 금액은 서로 다르다. 본체·연결 범위, 원·천원·백만원을 표마다 표시한다. 내부거래가 포함될 수 있는 종속회사 표를 단순 합산하지 않는다. 공시가 분리하지 않은 제품 금액을 추정하지 않는다. 예를 들어 원익머트리얼즈의 가스 병합 셀을 NH3 단독 매출로 표시하지 않으며, 티에스이 본체의 제품 구성을 연결 매출 비중으로 취급하지 않는다.

재무 자동 갱신과 달리 매출구성 스냅샷은 원문을 재검토한 뒤 교체한다. 화면의 기간·확인일을 기준으로 읽어야 한다.

## 수집과 검증

`update-semicon-supplychain.yml`: 매일 08:55 KST, 전년과 당년 정기보고서 재조회. 수동 전체 이력 재조회도 지원한다. 출처 장애 시 마지막 성공 이력을 보존하고 실패 상태를 표시한다. 장비 탭 수동 갱신에서도 추가 장비 기업을 갱신한다. 주가·PER·PBR은 기존 밸류에이션 워크플로에서 갱신한다.

```text
python scripts/fetch_semicon_supplychain.py --refresh
python -m unittest discover -s scripts -p test_semicon_supplychain.py -v
node scripts/test_semicon_supplychain.cjs
python scripts/verify_semicon_supplychain_ui.py --url http://127.0.0.1:8804/
python scripts/run_ci_tests.py
```

API 키는 GitHub Secret/환경변수에서만 읽으며 공개 JSON·원본 캐시·로그에 포함하지 않는다. 원본 다운로드용 reviewer는 키 없는 응답만 artifact로 내보낸다. 일부 장기 원본 수집이 중단되면 이미 완료한 기업을 건너뛰고 재개한다.

## 사용자 지정 블로그에서 추가한 8개사

[지정 글](https://blog.naver.com/cybermw/224479839109)의 기업명·6자리 종목코드 19개를 기존 밸류에이션 등록 목록과 대조했다. ISC·네오셈·GST·이엔에프테크놀로지·엘오티베큠·원익IPS·티에스이·네패스아크·케이엔솔·HPSP·솔브레인은 이미 있어 추가하지 않았다. 글의 예상 실적·시가총액·성장률은 재사용하지 않는다.

| 배치 | 신규 기업 | 해석할 때 구분할 범위 |
| --- | --- | --- |
| 부품 → 테스트 부품 | 오킨스전자, 마이크로컨텍솔 | 번인·테스트 소켓과 검사 장비 본체·후공정 서비스 구분 |
| 부품 → 플라즈마·RF 부품 | 뉴파워프라즈마 | RPG·RF 전원장치·정합기 외 연결 방산·복합소재·UTG 사업 포함 |
| 장비 → 공정 인프라 | 유니셈, 원익홀딩스 | 스크러버·칠러·가스 공급장치와 유지보수·그룹 연결 사업 구분 |
| 소재 → 공정 화학소재 | 퓨릿 | 반도체·디스플레이·산업용 용제와 자원재생 포함 |
| 장비 → 검사·계측 | 기가비스 | 패키지기판 AOI·AOR 장비이며 웨이퍼 검사·기판 제조와 구분 |
| 부품 → 고다층 PCB | 이수페타시스 | 서버·네트워크용 MLB이며 반도체 패키지기판·FC-BGA와 구분 |

분류는 회사 공시와 공식 제품 자료를 기준으로 했다. [뉴파워프라즈마 RF 제품](https://newpower.co.kr/sub/sub_02_02.php), [원익홀딩스 가스 공급·정제 사업](https://www.wonikholdings.kr/biz_02.do), [퓨릿 사업](https://www.purit.co.kr/사업분야/사업소개/), [기가비스 공시](https://kind.krx.co.kr/external/2024/08/14/001502/20240814004646/11012.htm), [이수페타시스 해외 제조법인·제품](https://www.petasys.com/eng/company/overseasbusiness.jsp), [유니셈 공시](https://kind.krx.co.kr/external/2024/03/07/001328/20240307002836/11011.htm), [마이크로컨텍솔루션 공시](https://kind.krx.co.kr/external/2026/05/14/001267/20260514002763/11013.htm).

원익홀딩스는 030530 존속법인의 이력을 보존한다. [2016년 원익IPS 분할 공시](https://kind.krx.co.kr/external/2016/05/16/001873/20160516004142/11013.htm)에 따라 분할일을 넘는 비교 및 2015·2016년 연간을 포함하는 성장률은 생략한다. 신설 원익IPS(240810)의 분할 전 실적으로 옮겨 넣지 않는다. 전환기 포인트에는 사업 범위 및 현금흐름 포함 범위의 주의를 표시한다.

추가 8개사의 주가·PER·PBR도 기존 매일 08:10 KST 밸류에이션 수집 대상에 포함한다. 재무는 기존 08:55 KST 수집 대상에 포함하며 새로 확보한 분기·연간 관측치와 원문 근거를 보존한다.

오킨스전자의 일부 과거 API 자료는 표준 취득 계정이 양수인 반면 사용자 정의 `공구와기구의 취득`만 음수다. [2021년 연간 원문 현금흐름표](https://dart.fss.or.kr/report/viewer.do?rcpNo=20220317000675&dcmNo=8470755&eleId=19&offset=224266&length=127257&dtd=dart3.xsd) 및 2019년 연간·2021년 1분기 원문에서 모든 취득 항목이 괄호로 표시된 현금유출임을 확인했다. 확인된 이 계정만 양수 취득 지출로 맞추고 원래 부호를 `original_signed_inputs`에 보존했다. 임의로 모든 음수 금액에 절댓값을 취하지 않는다.
