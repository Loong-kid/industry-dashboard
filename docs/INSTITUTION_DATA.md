# 기관 공시 데이터

기관 탭은 공시 접수일 기준으로 대량보유 이력을 표시한다. 지분율은 실시간 보유량이 아니며, 5% 미만 보고 이후의 실제 보유는 확인되지 않는다.

## 원본과 생성물

- `data/_dart/대량보유DB.csv`: 코스피·코스닥 대량보유 목록. 접수번호가 기본키이며 기업 고유번호 `corp_code`도 보존한다.
- `data/_dart/대량보유상세DB.csv`: `majorstock.json` 상세 및 검증된 `document.xml` 보강값. 기존 API 상세를 우선 보존한다.
- `data/institution/major_holdings.json`: 목록과 상세를 접수번호로 연결한 화면 데이터. `history`에 저장 시작일·공시 수·지분율 확인 수를 기록한다.
- `data/institution/holdings_traj.json`: 공시 기준 종목·보고자별 지분율 시계열.
- `manual/institutions.json`: 확인된 보고자명만 연결하는 관심기관 사전. 이름이 비슷하다는 이유만으로 펀드·관계사를 합치지 않는다.

## 과거 수집

2026-09-27 점검에서 `majorstock.json`은 삼성전자와 케이아이엔엑스에 대해 2024년 10월 이후만 반환했다. 이는 실제 관측이며 공식 API의 영구적인 기간 제한을 단정한 것은 아니다. 과거 공시 목록은 2022년부터 조회되므로 상세가 없는 건은 원문으로 보강한다.

`backfill-holdings` 수동 워크플로:

1. `scan`: `D001` 목록을 89일 단위로 수집하고 원문 표본을 보관한다.
2. `full`: `source_run`에 이전 실행 번호를 지정해 `holdings-backfill` 아티팩트를 이어받는다.
3. 기존 API 상세 160건과 원문 파서 결과를 비교한다. 불일치가 있으면 본 수집을 중단한다.
4. 누락 원문을 4,000건씩 처리하고 각 구간을 아티팩트로 저장한다. 이미 저장된 상세는 다시 받지 않는다.
5. API 한도 응답 `020`이 오면 완료분을 보존한다. 한도가 회복된 뒤 체크포인트 실행 번호로 이어받는다.

`holding_document.py`는 UTF-8을 우선하고 CP949로 폴백한다. `THS_STK_*`와 `SUM_TMT_*`의 현재 보유값을 대조하고 `MDF_STK_*`에서 증감을 읽는다. 계약비율 `CTR_*`는 보유비율로 사용하지 않는다. 누락값은 0으로 바꾸지 않고, 서로 모순되는 값은 검토 대상으로 남긴다. 아티팩트 `audit.json`에는 성공 원문의 해시와 실패 접수번호·사유가 남는다.

검증 후 목록·상세를 병합하고 `aggregate_major_holdings.py`를 실행한다. 다른 산업의 수집기를 실행할 필요는 없다.

일일 상세 수집은 최근 90일에 새로 접수됐거나 상세가 빠진 공시가 있는 기업을 대상으로 한다. API가 반환하지 않는 과거 누락 때문에 매일 전체 기업을 다시 조회하지 않도록 과거 보강과 분리했다.

## 관심기관 설명 및 운용 정보

`manual/institutions.json`의 `profile`은 공식 자료를 확인한 수동 관리 데이터다. 일일 DART 수집은 이 자료의 확인일이나 값을 갱신하지 않는다. `aggregate_major_holdings.py`가 기존 기관 사전과 함께 화면 JSON에 포함한다.

- `fact`와 `source`: 공식 자료로 확인한 투자 특징과 근거.
- `reason`, `watch`: 대시보드의 선정 목적과 관찰 포인트. 운용 성과에 대한 추천·인증이 아니다.
- `checked`: 사람이 출처를 확인한 날짜. 단순 재집계 때 변경하지 않는다.
- `aum`: 기준일, 원 단위 금액, 통화, 운용 범위, 출처를 가진 이력 배열. 펀드 순자산이나 미국 13F 보유액을 운용사 전체 AUM으로 대체하지 않는다.
- `funds`: 펀드명·클래스·통화·보수/세금 조건·비교지수와 `annual`(역년 수익률), `rolling`(기준일까지 기간 수익률)을 구분한다. 미확인은 0으로 채우지 않는다.

초기 확인(2026-09-29): AUM은 Grandeur Peak, Wasatch, Kopernik, LIFE 4곳; 성과는 Grandeur Peak Global Opportunities Investor와 Kopernik Global All-Cap Institutional 2개 펀드. Wasatch AUM은 2025-12-31 공표치로 오래된 값임을 화면에서 표시한다. 수치는 현재 실시간 값 또는 모든 공개 자료 중 최신 값으로 보장하지 않는다. LIFE는 한국어 공식 페이지의 `data-symbol="억원"` 단위까지 확인했다. Kopernik은 자문 전용 자산 포함 9.9B가 아닌 AUM 9.7B를 사용했다.

새 공표치를 추가할 때 같은 범위·통화의 AUM 이력을 보존하고, 성과는 동일 클래스와 기간을 유지한다. 원문·기준일·단위·보수 조건을 확인한 뒤 확인일을 갱신하고 기관 집계기만 실행한다. 연도별 화면에서는 실제 기준일과 연말/연중 구분을 표시한다. 공개하지 않는다는 사실을 확인하지 못했으면 '비공개'가 아니라 '미확인'으로 남긴다.

## 기관 분류와 연도별 운용규모 (2026-09-29)

`scripts/institution_registry.py`가 기존 관심기관, 금융투자협회 통계, DART 목록/상세의 보고자명을 합친다. 이 버전은 571개 기관·과거 명칭을 포함하고 168개가 저장 공시와 연결된다. 현재 인허가를 받은 모든 운용사의 공식 명부라는 뜻은 아니다. DART에 나타난 국내 운용·자문사 명칭의 누락을 독립적인 커버리지 검사로 확인한다. 영문 명칭 후보는 운용사로 단정하지 않고 `기타 운용기관·후보`로 표시한다.

- `watchlist`: 관심기관 8곳에만 true. 공시 필터·겹치는 종목·단축 버튼은 이 값을 사용한다.
- `region`, `kind`, `styles`: 지역, 기관 유형, 투자 스타일을 독립적으로 관리한다. 국내 여부는 금융투자협회 통계 수록 또는 수동 확인에 근거한다. 이름만으로 소재국·투자 스타일을 추정하지 않는다. 기관 유형은 명칭에 따른 분류이며, 법적 인허가 검증을 대체하지 않는다.
- `origins`, `dart_reports`, `dart_status`: 등록 근거와 저장된 접수번호 연결 상태. 목록·상세의 중복 접수번호는 한 번 센다. 상세에만 있는 접수번호 때문에 공시 목록 건수와 차이가 날 수 있다.
- `institution_aliases.json`: 공식 근거로 확인한 KB/케이비, BNK/비엔케이 연결. 주식회사·(주)·㈜ 및 공백·쉼표·마침표만 자동 정규화한다. 자회사·펀드·이름이 비슷한 법인, 합병 전후 명칭은 근거 없이 통합하지 않는다.

`manual/institution_aum/`에는 금융투자협회 종합통계포털에서 내려받은 표를 손실 없이 열 선택한 CSV가 있다. `sources.json`에 조회 경로, 설정, 단위, 원본 XLSX SHA-256, 기준일을 기록했다. 소계·합계·(기타)는 기관으로 넣지 않았다. 회사 수는 2022-12-30 411, 2023-12-29 465, 2024-12-31 490, 2025-12-31 502, 2026-09-28 505개다. 합산한 5개 시점의 명칭은 현재 활동 중인 회사 수와 다르다.

**국내 통계의 정의:** 펀드 > 회사 > 운용사통계 > 투자신탁/회사/일임/기관전용 사모펀드, 기금 전체=예, 단위=일억 원. 집합투자기구 등 소계와 투자일임을 합한 `계`를 사용한다. 페이지 유의사항은 **설정원본 기준**이며 ETF는 2008-03-19부터 순자산총액 기준이라고 명시한다. 따라서 평가액 기준 AUM과 동일하다고 표시하지 않는다. 원본 `-`는 CSV 빈칸/JSON null로 보존한다. CSV 단위는 억원, 생성 JSON은 원 단위다. 표시 반올림 때문에 구성액 합계 검증에는 1억원 오차를 허용한다.

화면의 `aum_history`는 `series`, `currency`, `scope`, `basis`가 같은 값끼리만 비교한다. 연도별 마지막 확인값을 사용하고 실제 기준일을 항상 표시한다. 2022~2025 자료는 연말, 2026-09-28은 연중이다. 전년 값이 연말이고 같은 계열일 때만 전년 말 대비 증감을 계산한다. 누락 연도는 연결·보간하거나 0으로 채우지 않는다. 라이프 공식 평가규모와 협회 설정원본은 별도 그래프로 유지한다. 해외 관심기관의 과거 연말 값은 아직 미확인인 경우가 있으며, 기존 확인값만 유지한다.

### 갱신 및 검증

KOFIA 자료는 자동 다운로드하지 않는다. 같은 화면·설정·단위에서 기준일을 선택한 뒤 EXCEL저장을 사용한다. 원본 첫 시트의 회사명, 집합투자기구 소계, 투자일임, 계 열을 각각 `name,funds,discretionary,total` CSV로 추출한다. `sources.json`에 기준일·연말/연중·기관 수·원본 해시를 추가하고 과거 CSV는 보존한다. 이후 `python scripts/aggregate_major_holdings.py`로 기관 데이터만 재집계한다. 일일 DART 작업도 이 집계기를 호출하므로 새 운용사 명칭은 자동 반영된다. KOFIA/공식 AUM은 별도의 확인 시점 자료다.

`python -m unittest discover -s scripts -p test_institution_registry.py`

커버리지, 관심기관 분리, 계열사 오통합 방지, 공식 별칭, 연말/연중 및 평가기준 분리, 원본 합계, 생성 JSON 연결을 검사한다. 배포 전 기존 공시 필드(기관 ID 제외)와 보유 추이가 보존되는지도 비교한다.

## 평가액 기준 AUM을 기본으로 전환 (2026-09-30)

기본 AUM은 금융투자협회 `펀드 > 회사 > 운용사통계 > 회사별설정규모 > AUM(펀드+투자일임)`에서 **순자산총액+평가액**을 선택한 값이다. 투자지역 전체, 펀드종류 전체, 기금 전체 예, 단위 일억원으로 조회했다. 공식 화면의 유의사항은 운용일 기준이며 추후 수정될 수 있는 자료라고 설명한다.

`manual/institution_aum_nav/`에 별도로 저장한다. CSV의 `total`은 원본 합계 열이며, `entrusted`는 참고 보존용 위탁운용 열이다. 위탁운용을 합계에 더하지 않는다. 투자일임기타 열을 전체 일임액으로 해석하지 않는다. 회사별 합계와 원본 `-`를 그대로 사용하며 소계·합계·(기타) 행은 기관으로 등록하지 않는다. XLSX 해시와 조회 조건은 sources.json에 기록한다.

- 2022-12-30: 414개
- 2023-12-29: 472개
- 2024-12-31: 497개
- 2025-12-31: 514개
- 2026-09-28: 519개 (연중 관측값)

새 `kofia_nav` 시계열은 JSON에서 원 단위다. 기존 `manual/institution_aum/`와 `kofia_principal` 시계열 및 운용사 공식 발표 값은 보존한다. NAV가 있으면 기본 그래프·연도 목록에 NAV를 사용하고 기존 설정원본과 운용사 별도 발표는 접힌 보조 자료로 제공한다. NAV가 확인되지 않은 기관은 확인된 운용사 공식 AUM을 사용하며, 설정원본으로 AUM을 대체하지 않는다. 서로 다른 기준의 연도를 연결하지 않고 AUM 증감률을 투자수익률로 표시하지 않는다.

통합 사전은 574개 기관·과거 명칭, DART 연결 169개, 관심기관 8개다. 기존 공시 필드와 보유 추이는 보존됐고 다올투자증권의 기관 연결만 추가됐다. 기존 설정원본 파일과 모든 과거 시계열 보존 및 7개 회귀 검사를 확인했다.

NAV 갱신도 동일 화면에서 해당 날짜를 조회하여 EXCEL저장한 뒤 회사명·합계·위탁운용 열을 추출하고 별도 NAV manifest에 추가한다. 기존 설정원본 갱신 절차와 경로는 유지한다. DART 일일 집계기는 두 계열을 함께 읽으며, KOFIA 스냅샷을 자동으로 최신화하지 않는다.

## 운용 범위별 투자성과 (2026-09-30)

기관 상세의 투자성과를 운용사 전체, 한국 주식 전략 종합, 개별 펀드·클래스로 분리했다. `profile.performance.company`와 `korea_equity`는 공식 종합 성과용 배열이며, `coverage_verified: true`인 레코드만 표시한다. 레코드는 name, coverage(포함 계좌·운용 범위), currency, basis(산출 방식·보수 기준), benchmark, checked, annual, rolling을 가진다. 모든 해당 계좌를 포괄하는지 공식 근거로 확인한 뒤에만 검증 플래그를 설정한다. 일부 상품의 단순 평균이나 AUM·설정원본 증감으로 종합 성과를 만들지 않는다. 현재 검증된 종합 성과는 없으며 미확인으로 표시한다.

기존 `profile.funds` 및 모든 수익률은 보존한다. Grandeur Peak와 Kopernik의 기존 공식 펀드 성과에 범위를 명시했다. MUST 공식 자산운용보고서(운용기간 2024-10-24~2025-01-23) 5쪽에서 원앤온리 자펀드 C-s(ED519)의 최근 3개월 7.76%, 6개월 14.14%를 확인하여 기간 성과로 추가했다. 보고서의 비교지수는 해당사항 없음으로, 본문의 임의 시장지수 비교는 공식 벤치마크로 전환하지 않았다. 이 역사적 관측치를 최신 성과나 역년 연간 수익률로 표시하지 않는다.

확인 경로: https://www.mustinvestment.com/uploads/7914569791_20250123_05401R200000_0.pdf#page=5
라이프 공식 Funds 페이지에서는 운용 규모와 전략 설명을 확인했으나 범위·기간이 갖춰진 성과표를 확보하지 못했다. VIP의 https://www.vipasset.co.kr/ 는 조회 시 403으로 자료 확인에 실패했다. 미확인은 비공개 또는 무성과를 의미하지 않는다. 전 운용사 상품 목록의 수집 완료를 주장하지 않는다.

초과수익은 같은 행의 공식 수익률에서 비교지수 수익률을 뺀 %p이며, 위험조정 알파가 아니다. 비교지수가 없으면 계산하지 않는다. 연간(1~12월)과 기간별 누적·연환산은 기존 구분을 유지한다. 공식 발표 수익률을 일괄 TWR이라고 단정하지 않고 자료에 명시된 산출 기준을 표시한다.
