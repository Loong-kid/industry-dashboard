# 기관 공시 데이터

기관 탭은 공시 접수일 기준으로 대량보유 이력을 표시한다. 지분율은 실시간 보유량이 아니며, 5% 미만 보고 이후의 실제 보유는 확인되지 않는다.

## 원본과 생성물

- `data/_dart/대량보유DB.csv`: 코스피·코스닥 대량보유 목록. 접수번호가 기본키이며 기업 고유번호 `corp_code`도 보존한다.
- `data/_dart/대량보유상세DB.csv`: `majorstock.json` 상세 및 검증된 `document.xml` 보강값. 기존 API 상세를 우선 보존한다.
- `data/institution/major_holdings.json`: 목록과 상세를 접수번호로 연결한 화면 데이터. `history`에 저장 시작일·공시 수·지분율 확인 수를 기록한다.
- `data/institution/holdings_traj.json`: 공시 기준 종목·보고자별 지분율 시계열.
- `manual/institutions.json`: 확인된 보고자명만 연결하는 관심기관 사전. 이름이 비슷하다는 이유만으로 펀드·관계사를 합치지 않는다.

## 과거 수집

2026-09-27 점검에서 `majorstock.json`은 삼성전자와 케이아이엔엑스에 대해 2024년 10월 이후만 반환했다. 이는 실제 관측이며 공식 API의 영구적인 기간 제한을 단정한 것은 아니다. 과거 공시 목록은 2022년부터 조회되므로 상세가 없는 건은 원문으로 보강한다.

`backfill-holdings` 수동 워크플로:

1. `scan`: `D001` 목록을 89일 단위로 수집하고 원문 표본을 보관한다.
2. `full`: `source_run`에 이전 실행 번호를 지정해 `holdings-backfill` 아티팩트를 이어받는다.
3. 기존 API 상세 160건과 원문 파서 결과를 비교한다. 불일치가 있으면 본 수집을 중단한다.
4. 누락 원문을 4,000건씩 처리하고 각 구간을 아티팩트로 저장한다. 이미 저장된 상세는 다시 받지 않는다.
5. API 한도 응답 `020`이 오면 완료분을 보존한다. 한도가 회복된 뒤 체크포인트 실행 번호로 이어받는다.

`holding_document.py`는 UTF-8을 우선하고 CP949로 폴백한다. `THS_STK_*`와 `SUM_TMT_*`의 현재 보유값을 대조하고 `MDF_STK_*`에서 증감을 읽는다. 계약비율 `CTR_*`는 보유비율로 사용하지 않는다. 누락값은 0으로 바꾸지 않고, 서로 모순되는 값은 검토 대상으로 남긴다. 아티팩트 `audit.json`에는 성공 원문의 해시와 실패 접수번호·사유가 남는다.

검증 후 목록·상세를 병합하고 `aggregate_major_holdings.py`를 실행한다. 다른 산업의 수집기를 실행할 필요는 없다.

일일 상세 수집은 최근 90일에 새로 접수됐거나 상세가 빠진 공시가 있는 기업을 대상으로 한다. API가 반환하지 않는 과거 누락 때문에 매일 전체 기업을 다시 조회하지 않도록 과거 보강과 분리했다.

## 검증

`python -m unittest discover -s scripts -p test_holding_document.py`

과거 원문 양식, CP949, 0% 이탈, 누락값, 요약/상세 불일치 및 계약비율 혼동을 검사한다. 자료를 게시하기 전 기존 접수번호 보존·연도별 건수·지분율 연결률·기관 화면을 확인한다.

## 2022년 이후 보강 결과 (2026-09-28)

공시 목록 48,009건 중 48,007건에 상세가 연결됐다. 기존 API 상세 22,497건을 보존하고 원문 상세 25,530건을 추가했다. 기존 상세 중 목록에 없는 20건도 삭제하지 않았다.

- 2022년: 목록·상세 8,581건
- 2023년: 목록·상세 9,424건
- 2024년: 목록 10,077건, 상세 10,076건
- 2025년: 목록·상세 10,214건
- 2026년: 목록 9,713건, 상세 9,712건

미확인 2건은 `20240930000404`(원문 API 응답 014), `20260122000414`(원문 보유비율 500.59%로 범위 검증 실패)다. 미확인 값을 0이나 추정치로 채우지 않았다.

표지와 상세 비율의 정밀도만 다른 6건은 두 값이 소수 둘째 자리에서 반올림해 같음을 확인하고 상세 표의 값을 사용했다. 원문 해시·파서 버전·미확인 사유는 `data/_dart/대량보유원문검증.json`에 보존한다.


## 관심기관 설명 및 운용 정보

`manual/institutions.json`의 `profile`은 공식 자료를 확인한 수동 관리 데이터다. 일일 DART 수집은 이 자료의 확인일이나 값을 갱신하지 않는다. `aggregate_major_holdings.py`가 기존 기관 사전과 함께 화면 JSON에 포함한다.

- `fact`와 `source`: 공식 자료로 확인한 투자 특징과 근거.
- `reason`, `watch`: 대시보드의 선정 목적과 관찰 포인트. 운용 성과에 대한 추천·인증이 아니다.
- `checked`: 사람이 출처를 확인한 날짜. 단순 재집계 때 변경하지 않는다.
- `aum`: 기준일, 원 단위 금액, 통화, 운용 범위, 출처를 가진 이력 배열. 펀드 순자산이나 미국 13F 보유액을 운용사 전체 AUM으로 대체하지 않는다.
- `funds`: 펀드명·클래스·통화·보수/세금 조건·비교지수와 `annual`(역년 수익률), `rolling`(기준일까지 기간 수익률)을 구분한다. 미확인은 0으로 채우지 않는다.

초기 확인(2026-09-29): AUM은 Grandeur Peak, Wasatch, Kopernik, LIFE 4곳; 성과는 Grandeur Peak Global Opportunities Investor와 Kopernik Global All-Cap Institutional 2개 펀드. Wasatch AUM은 2025-12-31 공표치로 오래된 값임을 화면에서 표시한다. 수치는 현재 실시간 값 또는 모든 공개 자료 중 최신 값으로 보장하지 않는다. LIFE는 한국어 공식 페이지의 `data-symbol="억원"` 단위까지 확인했다. Kopernik은 자문 전용 자산 포함 9.9B가 아닌 AUM 9.7B를 사용했다.

새 공표치를 추가할 때 같은 범위·통화의 AUM 이력을 보존하고, 성과는 동일 클래스와 기간을 유지한다. 원문·기준일·단위·보수 조건을 확인한 뒤 확인일을 갱신하고 기관 집계기만 실행한다. 화면은 기준일 또는 확인일이 180일을 넘으면 경과 일수를 표시한다. 공개하지 않는다는 사실을 확인하지 못했으면 '비공개'가 아니라 '미확인'으로 남긴다.
