# 조선 엔진·기자재·AM 실적

조선의 기존 시장·수주 화면을 첫 탭에 보존하고, 엔진 제조사·엔진 부품·AM/현대마린솔루션 탭을 추가한다. 현재 탭의 차트 3~9개만 생성하고 이전 탭 차트를 해제한다.

## 대상과 사업 범위

| 분류 | 회사 | 주의할 범위 |
|---|---|---|
| 엔진 제조 | 한화엔진(082740) | 구 두산엔진·HSD엔진 동일 법인 이력, 사업 재편·중단영업 포함 가능 |
| 엔진 제조 | HD현대마린엔진(071970) | 구 STX중공업. STX엔진과 별개. 과거 플랜트·구조조정 영향 |
| 엔진 제조 | STX엔진(077970) | 민수 엔진 외 방산 특수 엔진·전자통신 포함 |
| 엔진 부품 | 케이에스피(073010) | 엔진 밸브 외 단조·기타 사업과 신규 종속기업 포함 |
| 엔진 부품 | 케이프(064820) | 실린더 라이너 외 과거 금융투자 자회사 등 연결 범위 변경 포함 |

| AM·서비스 | HD현대마린솔루션(443060) | 엔진·기자재 AM/MRO 외 벙커링·친환경 개조·디지털 사업 포함 |

HD현대중공업 엔진기계는 별도 상장사가 아닌 사업부다. 중공업 전사 실적을 엔진 단독 실적으로 대입하지 않는다. 회사 간 매출 합계는 산업 시장규모가 아니다. 동일 그룹·관계기업 거래와 부품 공급이 중복될 수 있다.

공식 기업·사업 설명 링크는 `manual/shipbuilding-equipment/companies.json`에 둔다. 법인 식별은 OpenDART 고유번호 목록의 종목코드와 회사명/과거명으로 확인한다. 현 법인의 과거 명칭은 허용하되 다른 상장법인의 실적을 연결하지 않는다.

## 실적과 보고기간

무료 OpenDART 전체 재무제표의 연결(CFS)을 우선 사용한다. 연결 공시가 없는 기간에만 별도(OFS)를 조회하고, 각 금액 메모·원문 출처에 기준을 표시한다. 공시 API가 제공하는 2015년 이후 이력을 확보한다. 현대마린솔루션은 2016년 신설 이후 확보 가능한 운영기업 이력만 표시한다. 미확보 과거 실적을 0으로 채우거나 분할 전 현대중공업 실적을 이어 붙이지 않는다.

매출·영업손익·전체 당기순손익을 추적한다. 지배주주 귀속 순익·총포괄손익·EPS·세전이익을 순이익으로 사용하지 않는다. 음수 순손실은 보존한다. 1~3분기는 공시된 분기 단독 값을 사용하고, 미확보 시 같은 회계연도·연결/별도 기준의 인접 누적 차이만 허용한다. 4분기는 연간−9개월 누적으로 산출한다. 연결/별도 기준이 다르거나 누적 자료가 없으면 해당 분기를 생성하지 않는다.

원 공시 API가 제공하지 않는 과거 기간은 후속 정기 공시에 명시된 실제 비교표로만 보완한다. 분기 비교에는 `frmtrm_q_amount`(3개월)와 `frmtrm_add_amount`(누적)를 사용하며 `frmtrm_amount`를 분기로 오인하지 않는다. 연간 비교표의 전기·전전기 금액은 실제 연간으로만 사용한다. 원래 확보한 기간은 덮어쓰지 않고, 부족한 기간만 채우며 공시 접수일·연결/별도·비교표 사용 여부를 보존한다. 2015년 공시에 있는 2014년 연간 비교값도 이 기준으로 포함될 수 있다.

현재 연도 DART 공정공시의 실제 분기 잠정실적도 조회한다. 공시 원문의 보고기간·단위·연결/별도·당해실적 열을 확인한다. 전망·계획·누계·전년동기 열을 해당 분기 매출로 넣지 않는다. 기간·메모·출처에 잠정을 표시하고, 같은 분기 정기 재무제표가 확보되면 정기 공시로 교체한다.

## 통화·수집

원화 원자료는 백만 KRW로 보존한다. 실제 분기·연간 보고기간에 해당하는 ECB 일별 원/USD 평균으로 나누어 백만 USD를 표시한다. 원화 금액, 평균환율, 관측 기간·개수와 차감 구성 공시는 메모와 표에서 확인할 수 있다. 현재 환율이나 인접 분기로 대체하지 않는다.

`update-shipbuilding-equipment.yml`은 KST 09:30 매일 실행한다. 기존 Secret `DART_API_KEY`를 사용하며 키·인증 URL·오류 전문은 공개 파일과 로그에 저장하지 않는다. 조회 실패 시 이전 성공 자료를 보존하고 조회 상태를 표시한다. 공개 재무 필드·원문 링크만 상태 JSON에 저장한다.

```sh
python -m unittest discover -s scripts -p test_shipbuilding_equipment.py -v
python scripts/fetch_shipbuilding_equipment.py --full-history
python scripts/validate_shipbuilding_equipment.py
python scripts/run_ci_tests.py
```

로컬 키가 없으면 기존 CI Secret으로 PR 검증 수집을 실행하고 공개 데이터 artifact를 검토한다. 이미 확보한 상태 JSON과 환율로 `--offline` 재생성이 가능하다. 초기 수집 이후에는 전년도·당해 연도를 갱신하며 전체 이력은 보존한다. `--full-history`는 2015년 이후 정기 공시 전체를 다시 조회한다.
