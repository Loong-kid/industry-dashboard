# AGC 시트 실적·추정 매출

`agc_sheet_revenue.json`은 기존 구글 시트의 AGC 탭에서 사용자가 차트로 요청한
선택된 세 행만 보관한다. 전체 통합문서나 다른 회사의 재무자료는 복사하지 않는다.

- `C7`: 원본 단위는 백만 엔. 억 엔으로 표시할 때 100으로 나눈다.
- `D47:Y47`: 달력 분기 2026Q2부터 2021Q1까지 22개. 최신 전체 회사 매출 셀은
  비어 있어도 이 세부 매출 행은 채워져 있으므로 전체 회사 매출 행에서 기간을 추정하지 않는다.
- `D48:Y48`: 전자부재 공표 실적의 시트 반올림 정리값. 기존 공식 IR 카드의 정밀값과 구분한다.
- `D49:Y49`: EUV Mask Blanks 사용자 추정치.
- `D52:Y52`: DUV Photomask Substrate 사용자 추정치. 완성 블랭크 매출과 범위가 다르다.
- `D50:Y50`의 DUV 완성 블랭크 `~0` 문자열은 확정 실적 0으로 바꾸지 않는다.

추정 셀은 수기 숫자이며 수식·메모·산식 출처는 확인되지 않았다. 2024년 EUV 분기 추정
합계 400억 엔은 기존 공식 연간 값과 일치하지만 개별 분기의 정확성을 뜻하지는 않는다.
이 추정치는 공식 IR만 담는 `blankmask_japan_ir.json`과 분리해 관리한다.

`python scripts/aggregate_agc_sheet.py`로 카드 세 개를 재생성한다.
일일 CI는 보관된 스냅샷을 변환하며 비공개 시트의 최신 값을 자동으로 읽지는 않는다.
사용자가 시트를 수정한 뒤 재반영을 요청하면 해당 범위·기간·단위·추정 상태를 다시 읽고
스냅샷과 실제 `checked` 날짜를 갱신한다. 시트 공유 상태는 변경하지 않는다.
