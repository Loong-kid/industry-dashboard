# 세계 구리 광산 명부

원자재 → 구리 탭의 `세계 구리 광산 · 소유·생산·매장량` 표입니다.
편집 원본은 `manual/copper_mines.json`, 웹 배포본은
`data/commodities/comm_copper_mines.json`입니다. 자료 검토일은 2026-10-08입니다.

## 범위와 공개 자료의 한계

32개국 138개 광산·광산군·개발 자산의 공개 자료를 수록했습니다.
공개된 모든 소규모·비상장·역사 광산까지 조사한 세계 전수 명부가 아닙니다.
국제적으로 통일된 무료 광산별 소유·생산·매장량·평생 채굴량 데이터는 없으며,
운영사·거래소·정부·공공기관의 자료를 항목별로 전사했습니다.
누락 항목은 `null`로 보존합니다. ‘미확인’은 0이나 미생산을 뜻하지 않습니다.

광산군으로만 공시하는 경우 한 행으로 유지합니다. 예: Grasberg/PTFI,
Centinela, Candelaria, MATSA, Bor, Norilsk/Talnakh, Sudbury.
광산군 전체 수치와 구성 광산을 동시에 생산 합계에 넣지 않습니다.
개발 자산, 휴광, 폐광, 상태 미확인도 필터로 구분합니다.
이란 3개 광산은 2016 JOGMEC 자료만 확인되어 최신 상태를 ‘미확인’으로 보존했습니다.

## 숫자와 소유 기준

- 생산: 실제 구리 금속량. 원광·정광 총중량, 생산능력·계획, 정련량·판매량으로 대체하지 않습니다.
- `production[].basis`: 광산 100% 또는 기업 귀속 지분량을 명시합니다. Morenci는 FCX 72%, Zaldívar는 Antofagasta 50%, Collahuasi는 Glencore 44%, Antamina는 Glencore 33.75% 공시값입니다. 나머지를 암묵적으로 100%로 역산하지 않습니다.
- CY는 역년, FY는 회사 회계연도입니다. BHP/Sandfire는 6월 말 FY이며 원래 연도·마감일을 보존합니다.
- 매장량: P&P 또는 원문에 명시된 매장량. 경제적 채굴 가능성을 평가한 수치입니다.
- 자원량: M&I, Inferred, 전체 자원량 등 원문의 분류와 매장량 포함 여부를 명시합니다. 매장량과 더하지 않습니다.
- `Mt ore`는 원광 100만 톤입니다. 품위가 있어도 자동으로 회수가능 구리로 변환하지 않습니다.
- `t Cu`, `kt Cu`, `Mt Cu`, million/billion lb Cu는 단위만 t Cu로 표준화합니다. 1 lb = 0.00045359237 t. 함유량과 회수가능량의 차이는 `basis`에 남깁니다.
- 광산/운영법인 지분과 상위 상장사 주주 지분, 스트리밍·로열티를 구분합니다. 상위 유효 지분을 쓰는 Zijin 표는 별도로 표시합니다.
- 지분 일부만 확인된 경우 나머지 주주의 비율을 배분하지 않습니다. 전체를 확인한 행만 지분 합계가 100%인지 검사합니다.
- `ownership_date_kind`, `status_date_kind`: `reported`는 자료의 공시 기준일, `checked`는 날짜 미표기 운영사 페이지의 확인일입니다. 확인일이 새로운 연간 실적을 뜻하지 않습니다.

## 누적 생산과 채굴 이력

최초 생산연도는 회사 인수연도와 다릅니다. 연속 운영 시작, 가동식,
노천/갱내 전환 등 의미가 다른 연도는 `history_note`에 설명합니다.
`end_year`는 확인된 중단/종료연도이며 휴광을 영구 폐광으로 바꾸지 않습니다.

`cumulative`는 출처가 직접 밝힌 과거 누적 구리 생산입니다.
`period_total`은 연속된 연도의 동일 지분·물리적 범위·CY/FY 기준에서만 계산합니다.
`history_complete: true`와 최초 생산연도부터의 연속 이력이 모두 있어야 평생 누적으로 표시합니다.
현재 Kamoa-Kakula 2021–2025는 1,658,834 t Cu, Panguna 1972–1989는
운영사 공시 반올림 3 Mt Cu입니다. 기타 부분 기간 합계는 평생 누적과 구분합니다.
연간 생산량에 광산 나이를 곱해 누적 채굴량을 추정하지 않습니다.
원광 채굴량은 `ore_mined`에 별도로 기록하고 상세 보기에 표시합니다.

## 출처 및 갱신

각 수치에는 `sources`, `date`, `basis`, `locator`가 있고 소유·상태·역사 출처는 별도입니다.
`sources` 사전에는 운영사/공시 문서의 원문 URL, 제목, 발표 시점, 확인일을 보관합니다.
동적 운영사 페이지와 공시 PDF의 빈티지가 다를 수 있으므로 개별 기준일을 우선합니다.
일부 사이트는 자동 요청을 403으로 차단하지만 브라우저 또는 검색 인덱스에서 접근 가능합니다.
상태가 오래된 자산의 최신 자료, 미확인 지분, 시작연도, 광산별 연간 생산,
원광 채굴 및 누적 생산 이력을 순차적으로 추가해야 합니다.

원본을 수정하고 다음을 실행합니다.

```sh
python scripts/aggregate_copper_mines.py
python -m unittest discover -s scripts -p test_copper_mines.py -v
node scripts/test_copper_mines.cjs
```

집계기는 네트워크를 호출하지 않고 검토일을 오늘 날짜로 바꾸지 않습니다.
CI는 자료 검증 후 배포본을 다시 생성합니다. 누락 출처, 지분 합계 초과,
중복 광산, 잘못된 단위, 미래 실적 날짜, 불완전한 평생 누적 표시는 실패 처리합니다.
CSV는 현재 필터·정렬·생산연도를 따르고, 원문 단위·구분·전체 생산 이력·출처를 함께 내보냅니다.
