# 화장품 기업 실적

국내 상장사 중 브랜드·ODM 제조·해외 유통의 흐름을 함께 볼 수 있는 9개사를 선정했다. 시가총액 순위나 화장품 단독 매출 순위가 아니다. 아모레퍼시픽, LG생활건강, 에이피알, 클리오, 브이티 / 코스맥스, 한국콜마, 코스메카코리아 / 실리콘투를 구분한다. 각사의 공식 IR 링크와 연결 사업 범위는 `companies.json`에 적었다.

## 원문과 기간

- OpenDART 기업 고유번호를 종목코드와 법인명으로 확인한 뒤 정기보고서 전체 재무제표를 수집한다. API는 2015년부터 조회하며, 보고서의 전기 비교표시가 있는 경우 2014년까지 복원한다. 상장 전 자료는 실제 공시된 기간부터 쓴다.
- 매출·영업이익은 손익계산서의 실제 3개월 금액을 우선한다. 4분기는 연간에서 9개월 누적을 뺀다. 누적 금액이 3개월 칸에도 반복된 상장 전 반기·3분기 자료는 3개월 실적으로 간주하지 않는다. 이후 비교표시에서 실제 분기가 확인되면 보충한다.
- CAPEX는 현금흐름표의 유형자산 취득 현금지출이다. 총액을 우선하고, 세부 항목만 있을 때 해당 항목을 합산하며 환급은 차감한다. 무형자산·투자부동산·M&A·비현금 리스는 제외한다. 분기는 같은 회계연도·재무제표 범위의 누적 차감으로 구한다.
- 서로 다른 연결·별도, 비교표시·당기, 기준이 다른 누적액을 섞어 차감하지 않는다. 미확인 기간은 공백으로 남긴다. 연간 자료에 미완료 연도를 연율화해 넣지 않는다.
- 2014년 코스맥스는 분할 후 3월 1일부터 시작한 첫 회계기간이다. 해당 연간·분기 자료와 원문 기간에 이 사실을 표시한다.

## 최신 잠정 실적

정기보고서와 별도로 DART의 **연결재무제표 기준 영업(잠정)실적**을 확인한다. 공식 공시의 기간과 단위, 매출·영업이익을 확인할 수 있는 경우에만 추가한다. 이 자료는 분기와 출처에 `잠정`을 표시하며, 같은 분기의 정기보고서가 확보되면 정기보고서 값이 우선한다. 잠정 CAPEX를 추정하지 않는다. 따라서 매출·영업이익과 CAPEX의 최신 날짜가 다를 수 있다.

## 해석 범위

모두 전사 실적이다. LG생활건강의 생활용품·음료, 에이피알의 뷰티 디바이스, 한국콜마의 제약·음료·용기, 브이티의 과거 라미네이팅·기타 사업 등을 포함한다. 화장품 단독 실적으로 해석하지 않는다. 아모레퍼시픽과 코스맥스는 각각 지주회사가 아닌 상장 사업회사다. 코스메카코리아와 연결되는 잉글우드랩을 이중 합산하지 않는다. 실리콘투는 제조사가 아닌 유통사다. 가치사슬 기업 간 매출을 합산해 산업 총매출로 쓰지 않는다.

## 재생성과 자동 갱신

`collect_cosmetics_sources.py --full-history`는 최초 과거 원문을 수집한다. `--preliminaries-only`는 공식 잠정 자료만 확인한다. 원문 캐시는 `.cache/cosmetics/`에 키 없이 저장하며 공개 데이터에는 DART 원문 링크를 남긴다.

`fetch_cosmetics.py`는 원문 캐시를 정규화해 `data/cosmetics/state.json`과 27개 차트를 만든다. `--from-state`는 저장된 상태만으로 재생성한다. `--refresh`는 최근 2개 연도 정기 공시와 최신 잠정 공시를 확인하고 기존 과거 이력을 유지한다.

`update-cosmetics.yml`이 매일 한국시간 09:45에 실행된다. 원문 수집·검증 실패 시 해당 회사의 마지막 성공 이력을 보존하고 확인 실패를 표시한다. 시험은 `python -m unittest discover -s scripts -p test_cosmetics.py`로 실행한다.
