# 아익스트론 컨콜

사용자가 제공한 `Conference call` 폴더의 영어 PDF 7개와 기존 한국어 PDF 5개를 대조해 등록한 자료다. 2026 Q1·Q3는 새로 번역했다. 2025 Q1·Q3에만 실제 Q&A가 있으며, 나머지 5개 PDF는 경영진 발표문이다. 자료의 실적 분기와 회의일은 다를 수 있다(2025 Q4 회의일은 2026-02-26).

`YYYY-qN-ko.md`가 검수된 번역 원본이며 `review.json`에 분기별 문서 종류, 원문 페이지 수, 검수 주석을 보존한다. 문장·수치·질문·답변을 요약하지 않는다. 명백한 원문 오기도 수치 자체를 임의로 수정하지 않고 주석을 단다. 기존 번역 PDF와 영어 원본은 덮어쓰지 않는다.

공개 원문은 `data/semicon/aixtron-calls/*-original.pdf`에 원본 바이트 그대로 보존한다. 목록의 SHA-256으로 무결성을 확인한다. 기존 한국어 PDF의 파일명과 해시도 목록에 보존한다. PDF의 반복 머리글·꼬리글은 본문에서 정리하고 저작권 문구는 한 번 남긴다. 영어 보기에는 시각적 위치 순서로 추출한 텍스트를 사용해 굵은 글씨가 문장 뒤로 이동하는 문제를 방지한다. 정확한 지면은 원문 PDF로 확인할 수 있다.

번역을 수정한 후 `python scripts/build_aixtron_calls.py`로 JSON·다운로드용 Markdown·목록을 다시 만든다. 신규 PDF는 `--source-directory <폴더>`로 최초 가져오기할 때만 필요하다. API나 자동 번역 서비스를 호출하지 않으며, 일일 수집 작업은 이 자료를 덮어쓰지 않는다.

검증: `python -m unittest discover -s scripts -p 'test_mocvd_calls.py'`. 기존 MOCVD 검증 명령의 `test_mocvd*.py`에 포함된다. 번역 내용의 정확성은 자동 시험만으로 보증하지 않는다. 페이지 대조와 검수 기록을 함께 유지한다.
