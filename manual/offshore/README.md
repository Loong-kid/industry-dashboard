# 해양 시추 추적

기존 FLNG와 별개인 `#/offshore`에 시장·수급, 글로벌 리그, 계약 일정,
운영사 실적 4개 보기를 제공한다. 1차 대상은 Transocean, Valaris, Noble,
Seadrill, Odfjell Drilling, Borr Drilling이다.

## 자료와 집계

- 개별 설비와 계약을 분리한다. 소유 그룹, 지분, 관리사, 고객을 구분한다.
  개별 등기상 소유 법인이 확인되지 않으면 그룹 소유로 표시한다.
- ARO 9기, BC Ventures 5기는 JV로 분리한다. 실물 대수는 한 번만 세고,
  지분 50%를 대수 0.5기로 바꾸지 않는다. 회사 연결 매출·잔고와 합산하지 않는다.
- 월·분기·연도 표기는 그대로 보존한다. 시간축의 min/max는 해당 기간의
  범위이며 확정 날짜가 아니다. 총 계약금액을 기간으로 나눠 요율을 만들지 않는다.
- 공시 기준 상태는 설비별 출처일에 평가한다. 국가·해역은 보고서/계약의
  위치 표기이며 실시간 AIS가 아니다. 오늘 실제 작업 여부를 추정하지 않는다.
- 12/24개월 커버리지는 설비별 공시일 이후 확정 계약의 공개 구간만 사용한다.
  불확실한 시작·종료 경계를 제외한 보수적 하한이며, 중복 기간은 합친다.
  계약 기간 자체가 미확인인 행은 0%로 표시하지 않는다.
- 옵션, 조건부 계약, LOA, 정비는 확정 계약에서 제외한다. 매각·퇴역과 매각
  대기는 기본 목록·현역 집계에서 제외하고 이력으로 남긴다.
- 세계 시장은 Westwood 공개 월간판의 유형별 대수다. 6개사 목록이 전세계
  전수는 아니다. 확보율은 공개 대수로 재계산한다. 잔여 기간(rig-years)과
  회사별 매출 잔고(USD)는 단위·정의가 다르다.

## 수집과 검토

`python scripts/fetch_offshore_drilling.py`가 회사별 선대 원문과 SEC Company
Facts를 확인한다. `.github/workflows/update-offshore.yml`은 매일 KST 08:10
실행하며 성공 후 기존 Pages 배포로 연결한다. 키는 필요하지 않다.

Transocean/Borr는 공개 목록에서 새 PDF를 찾는다. Valaris/Seadrill은 검토된
PDF를 수집하고 공식 뉴스 피드로 새 FSR·계약 공시를 감지한다. 새 보고서의
주소·형식을 확인하기 전에는 최신 공시를 읽었다고 표시하지 않는다.
Noble FSR은 공식 원문을 대조해 입력한 자료로 보존하고, 공식 목록의 새
보고서 날짜를 감지해 검토 표시한다. Odfjell의 웹 선대는 매일 확인하되
웹 그래프의 폭으로 계약 날짜를 역산하지 않는다.

초기 세계 시장 관측, Noble FSR, JV/소유 보완, 인수합병·매각 사건, 비GAAP
실적은 `curated.json`에 출처와 기준일을 갖춘 검토 자료다. 새 공시를 확인한
후 해당 자료를 갱신한다. 확인일이 바뀌어도 공시 기준일은 바꾸지 않는다.
원문 접근·파싱 실패는 해당 회사의 마지막 성공 자료와 날짜를 유지하고
실패 상태를 기록한다. `.cache/offshore/` 원본은 Git·배포에서 제외한다.

`python scripts/fetch_offshore_drilling.py --offline`은 네트워크 없이 마지막
상태와 검토 자료로 공개 JSON을 다시 만든다.

## 재무 정의

SEC 표준 태그도 회사의 전체 매출을 뜻하는지 확인한다. Valaris/Seadrill의
일부 계약 매출 태그보다 총매출 Revenues를 우선한다. 분기는 달력상의 전체
분기만 사용한다. 현금흐름 등 누적 공시는 동일 회계연도 시작일의 차분으로
분기를 만든다. 구조조정으로 짧아진 부분 분기는 전체 분기로 취급하지 않는다.

매출·손익·현금흐름은 2023년 이후 확보한 구간을 제공한다. 빈 분기는 채우지
않고 선을 끊는다. 재무제표 기본 실적은 SEC 자동 수집, 회사별 조정 EBITDA와
효율 등은 별도 검토 자료다. 보험 효과를 포함한 Odfjell EBITDA와 다른 회사의
조정 EBITDA를 구분한다. Borr Dayrate Equivalent Backlog는 다른 회사의
명목 매출 계약잔고와 합산하지 않는다. FCF는 회사 공시 또는 영업현금흐름에서
유형자산 현금취득액을 뺀 값으로 구분한다. CAPEX가 없으면 FCF를 추정하지 않는다.

## 확인

Odfjell의 기본 실적·공시 EBITDA·현금흐름은 공식 분기 PDF의 손익·현금흐름표에서
자동 추출한다. 과거 보고서의 형식이 달라 추출하지 못한 구간은 빈값으로 유지한다.

```sh
python -m unittest discover -s scripts -p test_offshore_drilling.py -v
node scripts/test_offshore_drilling.cjs
```
