# 엔터테인먼트 4대 기획사

국내 대표 기획사 하이브(352820), 에스엠(041510), JYP Ent.(035900), 와이지엔터테인먼트(122870)의 **연결 전체** 실적을 표시한다. 시가총액 순위표나 순수 음반 매출 순위가 아니다. 기본 비교 화면과 HYBE·SM·JYP·YG 회사별 탭을 제공하며 매출·영업이익·CAPEX 12개 차트에 분기·연간 전환을 적용한다.

## 자료와 계산

- `companies.json`은 종목코드·법인명/과거 상호·사업 범위·공식 IR 링크를 기록한다. OpenDART 기업 고유번호는 종목코드와 법인명을 모두 확인해 매핑한다.
- 정기보고서 전체 재무제표를 2015년부터 조회하고 실제 전기 비교표시로 확인되는 경우 2014년까지 복원한다. 하이브 등 상장 전 자료가 제한되는 회사는 실제 확보 기간부터 표시하며 과거를 추정하지 않는다.
- 매출·영업이익은 실제 3개월 손익계산서를 우선한다. 4분기는 연간−9개월 누적이다. 상장 전 보고서의 누적 금액이 3개월 칸에도 반복되면 분기 실적으로 쓰지 않는다.
- CAPEX는 현금흐름표 **유형자산 취득 현금지출**이다. 총액을 우선하고 세부 취득 항목만 있으면 해당 항목을 합산한다. 환급은 차감한다. 같은 회계연도의 누적 차감으로 분기를 구한다.
- JYP 2019년 1·3분기는 원문 현금흐름표에서 `유형자산의 취득`과 `건설중인자산의 취득`이 각각 투자활동현금흐름의 독립 항목이다. 원문 투자활동 합계와 세부 항목 합산이 일치함을 확인한 두 접수번호에 한해 두 취득지출을 더한다. 반기·연간에는 이미 합쳐 공시되어 추가 합산하지 않는다. 근거는 `cash-review.json`에 보관한다.
- 음악 마스터·카탈로그·계약권 등 무형자산, 콘텐츠 제작비·선급금, M&A·투자부동산·비현금 리스는 CAPEX에 포함하지 않는다. 따라서 이 CAPEX는 엔터사의 전체 IP 투자액이 아니다. 사옥·시설 투자 등에 따라 변동이 클 수 있다.
- 연결 우선이며 연결이 없는 보고서는 별도임을 표시한다. 서로 다른 연결·별도, 당기·비교표시, 누적 기준을 혼합해 차감하지 않는다. 확인되지 않은 분기와 음수가 되는 유형자산 지출 차분은 공백으로 남긴다.
- DART의 공식 연결 영업(잠정)실적은 실제 기간·단위·매출·영업이익이 확인되는 경우에만 별도 표시한다. 정기보고서 확보 시 해당 분기는 확정 수치로 대체한다. 잠정 CAPEX를 추정하지 않으므로 지표별 최신 분기가 다를 수 있다.

## 해석

음반/음원, 공연, MD, 매니지먼트, 팬 플랫폼 및 해당 기간 종속기업을 포함하는 회사 전체다. 특정 아티스트의 매출로 환산하지 않는다. 해외 레이블 인수, 회사 매각·재편 및 계속사업 재분류에 따라 연결 범위와 과거 비교표시가 달라질 수 있다. 상장 관계사·자회사의 매출과 모회사 연결 매출을 합산하지 않는다. 순이익·조정 EBITDA를 영업이익으로 대체하지 않는다.

## 수집과 갱신

`collect_entertainment_sources.py --full-history`가 최초 과거 정기보고서와 공식 잠정 원문을 수집한다. 원문은 키 없이 `.cache/entertainment/`에 보관한다. `--preliminaries-only`는 기업 매핑과 잠정 공시만 확인한다.

`fetch_entertainment.py`는 원문 캐시에서 `data/entertainment/state.json`과 12개 차트를 만든다. `--from-state`는 저장 상태만으로 재생성한다. `--refresh`는 최근 2개 연도 정기보고서와 최신 잠정 공시를 확인하고 기존 과거 이력을 유지한다. `fetch_cosmetics.offline`에 별도 캐시 경로를 주는 방식으로 검증된 국내 공시 정규화·잠정 대체 규칙을 재사용하며 화장품 데이터 경로는 수정하지 않는다.

`update-entertainment.yml`이 매일 한국시간 **09:55**에 실행된다. 원문 수집·검증 실패 시 해당 회사의 마지막 성공 이력을 보존하고 확인 실패를 표시한다. 갱신은 엔터 데이터만 커밋하며 원문 링크는 각 관측값에 제공한다.
