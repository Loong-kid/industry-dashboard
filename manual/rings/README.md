# Si·SiC 식각 부품 실적

티씨케이(064760), 하나머티리얼즈(166090), 케이엔제이(272110), 월덱스(101160), 씨엠티엑스(388210)의 DART 정기 공시다. 법인 매핑은 OpenDART 고유번호 목록의 종목코드와 회사명을 모두 검증한다. 링·SiC 제품 단독 실적으로 간주하지 않는다.

`collect_ring_sources.py --full-history`는 2015년 이후 전체 재무제표를 내려받는다. OpenDART가 제공하지 않는 2014년 이전 요청을 반복하지 않고, 후속 사업보고서의 비교 열로 확인한 연간만 포함한다. 처음 확보한 연간/분기는 각각 티씨케이 2014/2015, 하나머티리얼즈 2015/2016, 케이엔제이 2017/2019, 월덱스 2014/2015, 씨엠티엑스 2023/2024년이다. 씨엠티엑스의 2024년 상반기 분기 CAPEX는 미확보다.

금액은 KRW 백만이다. 연결 공시를 우선하고 해당 보고서에 연결이 없으면 별도임을 보존한다. 티씨케이는 별도 재무제표다. 손익은 3개월 공시를 우선하고 4분기는 연간−9개월, 현금 CAPEX는 같은 연도의 누적−직전 누적이다. 정정·후속 비교표시의 공시일·금액·출처를 보존하며, 연결/별도·비교표시 여부가 다른 누적끼리는 차감하지 않는다. 최초 공시에 후속 기준을 섞어 역산하지 않고, 대체 비교표시를 쓰면 양쪽 누적의 공시 순서와 회계 범위를 확인한다.

CAPEX는 현금흐름표 유형자산 취득만 사용한다. 총액을 공시하면 세부항목을 다시 더하지 않는다. 총액이 없으면 토지·건물·구축물·기계·차량·공구·비품·건설중인자산·기타 유형자산 등의 명시된 취득 현금지출을 합산한다. 무형자산·투자부동산·금융상품·M&A·보증금·리스 비현금 증가는 제외한다. 각 항목이 나뉜 표의 대시/빈칸과 해당 회사 전체 지표 미확보를 구분한다.

씨엠티엑스 2026년 상반기 시설장치 취득 행은 현금환급이다. API가 반환한 −995,580,000원을 다른 취득 지출에서 차감한다. 항목별 절댓값을 더하지 않는다. 원문 [2026년 반기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260814004099)의 연결 현금흐름표에서 시설장치 +995,580,000원 유입을 대조했다. 유형자산 취득 순지출 합계 23,519,336,492원에서 Q1 8,247,917,748원을 빼 Q2 15,271,418,744원이다. 회귀 시험용 원 API 보고서 2개는 `statement-fixtures.json`에 키 없이 보관한다.

티씨케이 2018년과 월덱스 2015년 일부 현금흐름 누적 공시는 앞뒤 금액이 역전된다. 음수 분기를 CAPEX로 확정하거나 임의 보정하지 않고 공백으로 둔다. 케이엔제이는 디스플레이 사업 중단·매각에 따른 계속영업 분류 차이를 설명한다. 다른 사업 범위로 재분류한 연간과 과거 분기 합계를 억지로 맞추지 않는다.

`fetch_rings.py --refresh`는 최근 2개 회계연도를 매일 오전 8:45 KST 확인한다. 새 보고서가 아직 없으면 마지막 값을 유지한다. 원문 확인 실패 시 마지막 성공 실적과 성공일을 보존하고 확인 실패 상태를 표시한다. `--from-state`로 보관된 정규화 공시에서 차트를 재생성한다. 수집 인증키는 CI Secret만 사용하며 공개 파일·원문 링크·오류 로그·아티팩트에 기록하지 않는다.

씨엠티엑스의 상장 전 [2025년 반기보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20250822000416)는 6개월 손익만 공시해 API의 3개월·누적 열에 같은 값이 반복된다. 이 값을 Q2로 표시하거나 H1−Q2=0을 가짜 Q1으로 만들지 않는다. 2025년 Q2는 2026년 반기보고서의 실제 비교 3개월 매출 40,401,010,884원, 영업이익 13,688,726,106원으로 확인한다. 2024년 상반기는 독립 분기를 확인하지 못해 제외하며 분기 차트는 2024년 Q3부터다.

API 열의 정의는 [OpenDART 전체 재무제표 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)를 따르되 원문이 별도 3개월을 공시하지 않는 예외는 검토한 접수번호로 구분한다. 비금융 생산능력·출하량·제품별 매출은 기업별 공개 범위가 달라 이번 공통 실적 15개 그래프에 임의로 배분하지 않았다.
