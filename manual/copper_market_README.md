# 구리 워런트·정광 TC·수입 프리미엄

원자재 → 구리의 해설 및 추가 지표입니다. 개념 검토일: 2026-10-09.

## LME 구성

`manual/copper_market_sources.json`의 검토된 CNAL/有色宝 공개표를
`derive_copper_market.py`로 변환합니다. 현재 2026-10-02 한 시점입니다.
원문 이미지의 구리 행을 확인했습니다. 총 248,650톤, 등록 134,650톤,
취소 114,000톤이며 합계가 정확히 맞습니다. 원문 취소 비중 45.85%와
원문 전일 47.01%를 보존하고, 비중 차이는 −1.16%p입니다.

이는 사용자가 첨부한 보고서의 248,700톤·45.8%를 역산한 값이 아닙니다.
제공처·기준 시점이 다른 기존 LME 총재고에 합치거나 수치 차이를 강제로
수정하지 않습니다. 공식 원자료와 교차 검증하기 전까지 CNAL의 재공표임을 표시합니다.
반출 예정일, 실제 입출고, 이전 날짜의 물량을 취소 비중에서 추정하지 않습니다.
일간 전체 이력으로 표시하지 않고 자동 OCR 수집도 하지 않습니다.

정식 취득 경로는 LME **Stock breakdown report**입니다. 2일 지연 XLS에
금속·국가·지역별 총재고, 등록, 취소, 입고, 출고가 있습니다. 공식 사이트는
계정 로그인이 필요합니다. 장기 이력은 LME Historical data 서비스 또는
공식 데이터 벤더를 확인해야 합니다. 실제 출고와 취소를 동일하게 보지 않습니다.

## 정광 TC

`fetch_copper_tc.py`는 SMM 공식 `www-old.metal.com/Copper`의 공개
**SMM Copper Concentrate Index (Weekly), $/dmt**, 상품 201910240001만
읽습니다. 월간 지수 201910240002, 연간 장기계약, 트레이더 구매 지수는
섞지 않습니다. 2026-09-30 공개값은 −231.68 USD/dmt입니다.

초기 이력은 SMM 2026-09-04 공개 주간 기사에서 확인한 2026-08-28
−199.84, 2026-09-04 −200.31 두 값만 포함합니다. 기사의 공표 당시 값과
나중에 정정된 가격표의 빈티지가 다를 수 있습니다. 날짜별 출처와 확인일을 보존합니다.
로그인으로 잠긴 과거 값·차트의 숨겨진 페이로드를 추출하지 않습니다.
공식 공개값을 매일 확인하되 `updated`는 지수의 원래 날짜입니다.
접근 실패·회귀·수정치 충돌은 기존 관측값·수집일을 보존하고 상태만 표시합니다.
빈 주는 생성하지 않습니다. 7일 초과 간격은 점선입니다.

단위는 **건조 정광톤**, 구리 금속톤이 아닙니다. 음수도 유효합니다.
RC는 별도 계약값이므로 TC의 1/10이나 고정 비율로 생성하지 않습니다.
전체 과거 이력·API는 SMM 회원 서비스의 권한과 이용 조건을 확인해야 합니다.

## 양산 프리미엄 차이

기존 Mysteel 창고증권·B/L `source_records`의 같은 날짜·제조 경로만
대응시킵니다. 계산은 **보세창고 중간값 − B/L 중간값**입니다.
제공처·원문 단위·중복·가격 범위를 검증하며 빠진 날짜는 제외합니다.
화법·습법을 섞거나 SMM 값과 이어 붙이지 않습니다.
양쪽 `delivery_pricing_terms`를 결과의 `source_records`에 보관합니다.
QP·ETA·브랜드·금융·보관 조건의 차이가 포함되므로 순수한 즉시 인도
프리미엄 또는 확정 차익이라는 이름을 쓰지 않습니다.

## 실행·검증

```sh
python scripts/fetch_copper_tc.py
python scripts/derive_copper_market.py
python -m unittest discover -s scripts -p test_copper_market.py -v
```

CI는 양산 원자료 확인 뒤 TC 공개값을 확인하고, LME 검토표와 차이를 계산합니다.
편집 원본과 파생 데이터의 재현성 검증은 파생 계산 뒤에 실행합니다.
해설은 `assets/copper-market.js`이며 데이터의 출처와 확보 범위를 함께 표시합니다.
