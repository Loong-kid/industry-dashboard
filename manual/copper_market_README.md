# 구리 워런트·정광 TC·수입 프리미엄

원자재 → 구리의 해설 및 추가 지표입니다. 개념 검토일: 2026-10-09.

## LME 구성

`fetch_copper_lme_warrants.py`가 [Minmetals Financial Services 공개 아카이브](https://www.mjfins.com/Service/LMEData/)의 일별 PDF를 읽습니다.
확인한 공개 파일의 최초 기준일은 2021-07-29이며, 2026-10-08까지 1,296개 기준일을 확보했습니다. 2021-01-01~2026-10-08의 모든
평일 파일명을 확인했으며 원문 날짜·구리 행·총재고=등록+취소·취소 비중을 검증합니다.
`source_records`에는 파일 URL, PDF SHA-256, 추출 방식, 원문 반올림 비율,
입출고와 전일 재고도 보관합니다. 날짜가 잘못 붙은 파일은 해당 날짜의 값으로 넣지 않습니다.
본문 비중은 원문의 톤수로 직접 계산하며 누락 날짜를 채우지 않습니다.
2025-06-23 파일은 확장자·응답 유형이 PDF지만 실제 내용은 PNG입니다.
원본 이미지의 날짜와 구리 8개 수치 셀을 직접 읽어 검증했으며 추출 방식과 SHA-256을 남겼습니다.
다른 이미지 파일을 자동으로 수기 검토 완료 처리하지 않습니다.

2021년 스캔 파일은 일회 OCR로 가져오고 서로 다른 두 해상도에서 모든 수치가
일치해야 합니다. 최근 텍스트 PDF는 OCR 없이 읽습니다. 실제 입출고는
전일 재고+입고−출고=총재고가 맞는 행만 별도 보기에 표시합니다. 원문의
입출고 오류가 있어도 총재고·등록·취소가 검증되면 재고 이력은 유지합니다.
오류 값을 차액으로 역산해 고치지 않습니다. `archive_audit`에 미공개·검증 실패 날짜를 남깁니다.

기존 CNAL 한 시점은 `manual/copper_market_sources.json`에 참고 원문으로
보존합니다. 자동 일간 아카이브가 확보되면 `derive_copper_market.py`가 이를
단일 시점으로 덮어쓰지 않습니다. `collection_provider=mjfins_archive`로 식별합니다.
독립 공개 차트 COMIDRA는 PDF와 대조한 다수 날짜에서 총재고와 취소 물량의
기준일이 불일치해 과거 보충 자료로 사용하지 않았습니다.

정식 취득 경로는 LME **Stock breakdown report**입니다. 2일 지연 XLS에
금속·국가·지역별 총재고, 등록, 취소, 입고, 출고가 있습니다. 공식 사이트는
계정 로그인이 필요합니다. 장기 이력은 LME Historical data 서비스 또는
공식 데이터 벤더를 확인해야 합니다. 실제 출고와 취소를 동일하게 보지 않습니다.

## 정광 TC

**주 이력:** `fetch_copper_tc_mysteel.py`가 [Mysteel 정광 홈페이지](https://tongjingkuang.mysteel.com/)의 공개
달러 가격 차트에서 TC 코드 `ID01154994`의 전체 응답을 읽습니다.
동일 차트의 현물 정광 가격 `ID01154993`, 위안화 국산 정광 가격,
SMM·SHMET 지수를 혼합하지 않습니다. 홈페이지가 사용하는 공개 endpoint는
`https://api.mysteel.com/publishd/index/chart/zhanTingData`이며
`indexCodes=ID01154994&startTime=2000-01-01`로 조회했습니다.
확보 범위는 **2013-01-11~2026-10-09, 1,679개 관측값**입니다.
초기 주간·2021~2025 일간·최근 주간 중심의 원문 발표일을 그대로 보존합니다.
단일 코드라는 이유로 모든 과거 시점의 조사 방법·계약 조건이 같다고 가정하지 않습니다.

단위는 USD/건조정광톤입니다. 날짜별 원문 문자열과 수치, 출처·확인일을
보존합니다. 공개 일보의 2024-07-24 9.5, 2024-12-26 7.75 USD/dmt와
차트의 같은 기준일 값을 별도로 대조했습니다. 일간 값과 주간 평균·주간
조사값은 다를 수 있어 기사 주간값으로 일간 차트 값을 덮어쓰지 않습니다.
빈 날짜는 보간·이월하지 않으며 전체 과거 값이 수정되면 자동 반영 대신
검토 오류를 내고 기존 이력을 보존합니다.

**별도 SMM 참고 카드:**

`fetch_copper_tc.py`는 SMM 공식 `www-old.metal.com/Copper`의 공개
**SMM Copper Concentrate Index (Weekly), $/dmt**, 상품 201910240001만
읽습니다. 월간 지수 201910240002, 연간 장기계약, 트레이더 구매 지수는
섞지 않습니다. 2026-09-30 공개값은 −231.68 USD/dmt입니다.

초기 이력은 SMM 2026-09-04 공개 주간 기사에서 확인한 2026-08-28
−199.84, 2026-09-04 −200.31 두 값만 포함합니다. 기사의 공표 당시 값과
나중에 정정된 가격표의 빈티지가 다를 수 있습니다. 날짜별 출처와 확인일을 보존합니다.
로그인으로 잠긴 과거 값·차트의 숨겨진 페이로드를 추출하지 않습니다.
공식 공개값을 매일 확인하되 `updated`는 지수의 원래 날짜입니다.
접근 실패·회귀·수정치 충돌은 기존 관측값·수집일을 보존하고 상태만 표시합니다.
빈 주는 생성하지 않습니다. 7일 초과 간격은 점선입니다.

단위는 **건조 정광톤**, 구리 금속톤이 아닙니다. 음수도 유효합니다.
RC는 별도 계약값이므로 TC의 1/10이나 고정 비율로 생성하지 않습니다.
전체 과거 이력·API는 SMM 회원 서비스의 권한과 이용 조건을 확인해야 합니다.

## 양산 프리미엄 차이

기존 Mysteel 창고증권·B/L `source_records`의 같은 날짜·제조 경로만
대응시킵니다. 계산은 **보세창고 중간값 − B/L 중간값**입니다.
제공처·원문 단위·중복·가격 범위를 검증하며 빠진 날짜는 제외합니다.
화법·습법을 섞거나 SMM 값과 이어 붙이지 않습니다.
양쪽 `delivery_pricing_terms`를 결과의 `source_records`에 보관합니다.
QP·ETA·브랜드·금융·보관 조건의 차이가 포함되므로 순수한 즉시 인도
프리미엄 또는 확정 차익이라는 이름을 쓰지 않습니다.

## 실행·검증

```sh
python scripts/fetch_copper_tc.py
python scripts/fetch_copper_tc_mysteel.py
python scripts/fetch_copper_lme_warrants.py
python scripts/derive_copper_market.py
python -m unittest discover -s scripts -p test_copper_market.py -v
```

CI는 양산 원자료 확인 뒤 LME 공개 일별 보고서·Mysteel TC 전체 공개 이력·SMM
참고값을 확인하고, LME 이력을 보존하며 프리미엄 차이를 계산합니다.
편집 원본과 파생 데이터의 재현성 검증은 파생 계산 뒤에 실행합니다.
해설은 `assets/copper-market.js`이며 데이터의 출처와 확보 범위를 함께 표시합니다.
