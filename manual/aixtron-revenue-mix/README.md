# AIXTRON 장비·After Sales와 용도별 매출

공식 자료 목록: https://www.aixtron.com/en/investors/publications

2022 Q1~2026 Q3 IR Presentation 19개를 페이지 단위로 대조했다. `data/_mocvd/facts.json`의 `aix_revenue_mix`에는 원문 URL, PDF 페이지, 원문 SHA-256, 분류, 인쇄된 비중, `<1%` 한계 표시와 반올림 범위를 보존한다. 장비·연결 매출의 금액은 기존 정기보고서의 `equipment_ytd`, `revenue_ytd`를 사용한다.

## 계산

- 장비 분기 매출 = 당기 누적 장비매출 − 직전 분기 말 누적 장비매출. Q1은 해당 누적 금액 자체.
- After Sales(부품·서비스 등) = 연결 매출 − 장비 매출. IR의 반올림된 75%·25% 등을 연결 매출에 곱해 대체하지 않는다.
- 용도별 누적 매출 추정 = 해당 기간의 **누적 장비매출 × 해당 기간의 누적 용도 비중**.
- 용도별 분기 매출 추정 = 당기 누적 추정 − 직전 누적 추정. Q4는 FY−9M. 분기 장비매출에 누적 비중을 곱하는 방식은 사용하지 않는다.

금액은 백만 EUR다. IR이 정수 비중을 반올림하므로 표에는 ‘약’으로 표시하고 그래프 제목에 환산 추정임을 표시한다. 인쇄된 비중 합계가 99~101%여도 강제로 100%로 정규화하거나 기타 항목에 잔여액을 배분하지 않는다. 합계 차이도 계산 원자료에 보존한다.

`<1%`는 0%나 0.5%로 확정하지 않는다. 관련 분기의 금액 중심값은 `null`이며 계산 가능한 조건부 범위만 보존한다. 누적 환산의 반올림 차분이 음수로 나오면 0으로 만들지 않고 금액을 미확정으로 둔다. 범위는 정수 비중을 최근접 정수로 반올림(±0.5%p), 장비매출은 0.1백만 반올림(±0.05백만)했다는 가정하에 구한 조건부 범위이며 통계적 신뢰구간이 아니다.

## 분류와 표시

2024년부터 공시된 GaN-Power·SiC-Power를 개별 표시한다. 이전 Power Electronics 합산 비중을 개별 항목으로 나누지 않는다. 상세 보기(2024~)와 전력 합산 보기(2022~)를 제공한다. 광전자·통신은 소비자 광학·태양광·통신 등을 포함해 InP 단독 매출이 아니다. 수주 용도 비중과 매출 용도 비중도 섞지 않는다.

기존 `mocvd_aix_applications` 연간 카드의 2025년 공시 금액과 이전 검토 이력은 유지한다. 이를 반올림 비중 환산치로 덮어쓰지 않는다.

새 문서:

- `mocvd_aix_application_revenue`: 용도별 분기 매출 추정. 기본 상세 / 과거 전력 합산 보기. `calculation_details`에 분기별 계산식·범위·장비매출과의 합계 차이 보존.
- `mocvd_aix_application_share`: IR에 인쇄된 **연중 누적 장비매출 비중**. 분기 단독 비중이나 총매출 비중으로 표시하지 않는다.
- `mocvd_aix_revenue_breakdown`: 분기별 장비·부품/서비스·용도별 추정액과 당기/직전 IR 링크를 표시하는 숫자표.
- `mocvd_aix_revenue`: 기존 분기 금액을 보존하며 공시 연간 금액 전환을 추가.

## 수집과 검증

`scripts/fetch_mocvd.py`의 기존 수집 일정에 포함된다. 일반 실행은 최신 연도 IR를 확인하고, `--backfill`은 현재 목록의 2022년 이후 전 기간을 확인한다. `--offline`은 저장된 원문 수치로 재생성한다. 실패 시 기존 성공 기록을 보존하고 새 문서에 확인 실패 상태를 표시한다.

2024년 이후 도넛은 가운데 용도 비중만 읽고 양옆 장비·서비스 및 지역 도넛을 배제한다. 범례 색과 각 비중 숫자 배경색을 일대일 대응시키므로 PDF 내부 텍스트 저장 순서가 달라도 GaN·SiC를 바꾸어 읽지 않는다. 붙어 있는 `6%2%`는 원문 문자 좌표로 분리한다. 색 매핑·공시 기간·분모·비중 합계를 검증하고 모호하면 자동 수집을 중단한다. 2022~2023년은 시각 대조한 당시 도표 순서와 `<1%` 표시를 사용한다.

검증 명령: `python -m unittest discover -s scripts -p 'test_mocvd*.py' -v`.
