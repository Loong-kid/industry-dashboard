## 일반 GPU

2026-10-25 공식 Geekbench OpenCL·Vulkan 차트에서 Geekbench 7임을 확인했다.
35개 GPU에 API별 점수 69개를 추가했다. 각 차트의 정확한 장치명을 연결하며
드라이버별 이름·노트북/데스크톱·상위 모델 결과를 합치지 않았다. 차트는 사용자
결과 5개 이상 장치명의 평균 집계다. 원본 Time Spy는 사용자가 기록한 대표·중앙값을
유지하며 이번에 새로 측정하거나 최신 차트로 바꾸지 않았다.

RTX 3060·Arc A770의 공식 차트 이름은 VRAM 용량을 특정하지 않는다. 해당 점수는
GPU 장치명 집계이며 원본 행의 12GB·16GB 구성 전용 점수가 아니라는 조건을
각 셀에 명시한다. Arc 140T·140V는 16GB 표기 장치명의 대표 집계다.
Iris Xe 96EU·Iris Plus G7 64EU·Arc 8-Core·Graphics 4 Xe3 등에서 코어 수를
특정하지 못하는 일반 이름의 점수를 임의 연결하지 않았다. 오래된 HD3000도
미확보 점수는 빈칸으로 둔다. API·버전 간 점수를 환산하지 않는다.

RTX 40/50 노트북 6종의 비어 있던 FP32에는 NVIDIA 공식 CUDA 코어 수·최대 부스트를
근거로 `CUDA 코어 수 × 2 FLOP/FMA × MHz ÷ 1,000,000`의 TFLOPS를 산출했다.
‘이론 산출’ 표기를 붙이고 계산식·입력값·원문을 메모에 표시한다. 지속 성능이나
실측 벤치마크가 아니며 TGP·발열에 따라 달성하지 못할 수 있다. 다른 GPU의
미확인 FP32·Time Spy 빈칸을 비례 추정으로 채우지 않는다.
원본 AI TOPS 열의 제목에는 INT8이 적혀 있으나 제품별 정밀도·Sparse 조건을
이번에 전부 확인한 것이 아니므로 화면 제목은 ‘원본 정밀도 미검증’으로 표시한다.
원본 제목은 `source_label`과 원본 스냅샷에 보존한다.

## NVIDIA AI

원본 30개 항목에 공식 자료의 추가 프로파일 4개를 더해 34개를 제공한다.
기본 필터는 ‘GPU 모듈’이다. 슈퍼칩·DGX 서버·랙·아키텍처 최대·네트워크를
선택해 보며, GPU 1개와 서버·랙 총합을 같은 기준으로 정렬 비교하지 않는다.
AI FLOPS는 제조사 이론 성능이며 Geekbench·Time Spy가 아니다.

- H200의 원본 `4.8GB/s`는 공식 SXM 사양 `4.8TB/s`로 정정한다.
- A100은 80GB SXM, H100/H200은 SXM 프로파일을 명시한다.
  H100/H200의 FP8·FP16 공식 Sparse 값을 절반으로 나눈 Dense 값은 계산임을 적는다.
- B200 HGX/DGX의 GPU당 메모리 180GB·대역폭 8TB/s는 DGX 8GPU의 1440GB·64TB/s를
  8로 나눈 값이다. 192GB는 아키텍처 최대치로 별도 분류한다. ‘Full B200’이라는
  원본 명칭을 독립 공식 판매 SKU로 확정하지 않는다.
- B300 HGX는 데이터시트의 270GB·7.7TB/s·최대1100W,
  GB300용 단일 GPU는 279GB·8TB/s·최대1400W로 분리한다.
  288GB 아키텍처 최대치와 제품 열의 용량을 구분한다. FP4의 Dense 14/15와
  Sparse 18/20은 단순한 2배 관계가 아니므로 값을 그대로 옮긴다.
- GH200의 HBM3 96GB/4TB/s와 HBM3E 144GB/4.9TB/s를 별도 행으로 둔다.
- Rubin NVL72 현재 제품 표의 GPU 288GB·19.2TB/s·NVLink3TB/s와,
  HGX Individual GPU/아키텍처 최대 표의 22TB/s·NVLink3.6TB/s를 분리한다.
  서로 다른 공식 프로파일을 한 행에 섞지 않는다. NVFP4 추론 Sparse와 학습 Dense를
  구분하고, FP8·FP16 Dense 학습을 Sparse 값으로 오인하지 않는다.
- DGX A100은 640GB 모델, DGX H100/H200은 각 640/1128GB 8GPU 서버다.
  DGX B200은 별도 추가 프로파일이다. 전력은 PSU 정격 합계 대신 시스템 최대치다.
- 원본의 ‘DGX GB200’은 72GPU 랙 계열로 분류하고 NVL72 행을 참조한다.
  동일 랙 수치를 복제해 합계에 두 번 더하지 않는다.
- GK180·GM200·DGX-1의 보드/변형과 사용자 NVL36×2 구성, 초기 B100 및
  네트워크 부품의 미검증 항목은 원본으로 표시한다. 정확한 제품 대응을
  확인하지 않은 값을 임의 보완하지 않는다. 검증한 셀만 출처 표시를 붙인다.

주요 근거는 각 셀의 NVIDIA 공식 제품 표·사용자 가이드·기술 해설·데이터시트다.
Dense/Sparse 쌍은 화면에서 Dense / Sparse 순서로 통일하며, 단일 원본 수치의
기준을 확인하지 못하면 ‘원본 D/S 미검증’으로 표시한다. 원본 Google Sheet는
수정하지 않으며 프로파일별 보완·정정과 원문 확인일을 함께 유지한다.

## 화면과 갱신

CPU와 같은 40px 고정 행·제품명 고정 열·말줄임·마우스 메모·상세 창을 사용한다.
상세 버튼은 CPU·GPU·AI 표 모두 가장 오른쪽이다. 열 보기·기업·형태/제품 단위·검색·
숫자 점수 정렬을 지원한다. GPU 표에는 시계열 기간 필터나 자동 갱신 버튼을 표시하지 않는다.
이 자료는 2026-10-25에 원문을 검토한 스냅샷이며 자동 실시간 갱신이 아니다.
다음 업데이트는 연결된 Sheets로 두 탭을 다시 읽고 원문 검토 후 보완 JSON을 갱신한다.

재생성: `python scripts/aggregate_gpu_specs.py`

데이터 검증: `python -m unittest discover -s scripts -p test_gpu_specs.py -v`

화면 검증: `python scripts/verify_gpu_specs_ui.py --url http://127.0.0.1:8792/`
