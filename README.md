# 산업 KPI 대시보드 (Industry Dashboard)

https://loong-kid.github.io/industry-dashboard/

PPI 모니터: https://loong-kid.github.io/industry-dashboard/#/ppi

PPI는 12개 대분류의 대표 산업 지도에서 시작한다. 관심 테마·산업 계층·관심 목록과 기존 비교·스캐너를 제공한다.
사용법·데이터 갱신·기존 배포 종료 안내: [PPI 모니터](docs/PPI_MONITOR.md).

게임 시장: https://loong-kid.github.io/industry-dashboard/#/games

무료 공개 자료로 시장 규모, Steam 월별·연도별 장르 이용량, Google Play 다운로드 관측, App Store 국가별 게임 차트를 제공한다. [지표 범위와 갱신 방법](docs/GAME_MARKET.md).
